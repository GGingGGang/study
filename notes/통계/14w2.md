# 14주 2강 — 범주형 자료 검정: 적합도 검정 · 독립성 검정

> 통계학 · 가설검정 (8장)
> 학습내용: 범주형 자료의 적합도 검정, 독립성 검정 (모두 카이제곱 통계량 사용)

---

## 1. 수업 요약

수치적 자료가 아닌 **범주형 자료**에 대한 검정을 다룬다. 이론적 분포와 관측값의 일치를 따지는 **적합도 검정**과, 두 변수의 독립 여부를 따지는 **독립성 검정**을 학습한다. 두 검정 모두 **카이제곱 통계량**을 사용하며 항상 **상단측검정**이다.

---

## 2. 개념 정리

### (1) 적합도 검정 (Goodness of Fit Test)
- **이론적으로 기대되는 분포와 실제 관측값이 맞는지(적합한지)** 검정
- 예: 주사위가 공정한가(각 눈 $1/6$), **멘델의 유전법칙(9:3:3:1)**이 맞는가
- **기대도수($E_i$)** = 이론적으로 기대되는 각 범주의 도수 (= 전체 시행 $\times$ 기대확률), **관측도수($N_i$)** = 실제 관찰된 도수
- **카이제곱 통계량: $\chi^2 = \sum \dfrac{(N_i - E_i)^2}{E_i}$** (분모 = 기대도수, 분자 = $(\text{관측}-\text{기대})^2$)
- **자유도 = 범주(카테고리) 수 − 1 = $k - 1$**
- 유도: 2범주 → 이항분포 → CLT로 정규분포 → 표준화 → 제곱 → **$\chi^2$(자유도 1)**
- **기각역**: 관측도수와 기대도수의 차이가 크면($\chi^2$이 크면) $H_0$ 기각 → **항상 상단측검정**
- 예: 주사위 6범주, $\chi^2=7.2 < \chi^2_{0.05}(5)=11.07$ → 채택(공정) / 멘델 $\chi^2=3.174 < \chi^2_{0.05}(3)=7.815$ → 채택(맞음)

### (2) 독립성 검정 (Test of Independence)
- **두 변수(요인)가 서로 독립인지(관련이 있는지)** 검정
- 예: 신상품 선호도 $\times$ 성별, 선호과목 $\times$ 성별 — **분할표(2차원, 두 변수)** ↔ 적합도(1차원, 한 변수)
- 독립 정의: **$P(A_i \cap B_j) = P(A_i) \cdot P(B_j)$** → **$H_0$: 두 변수는 독립이다**
- **기대도수: $E_{ij} = N \times \hat{p}_{i\cdot} \times \hat{p}_{\cdot j} = \dfrac{(\text{행합}) \times (\text{열합})}{\text{전체 } N}$**
- **카이제곱 통계량: $\chi^2 = \sum\sum \dfrac{(N_{ij} - E_{ij})^2}{E_{ij}}$** (셀이 가로·세로 두 종류 → **더블 서메이션**)
- **자유도 = (행 범주 수 − 1)(열 범주 수 − 1) = $(r-1)(c-1)$**
- 기각역: 차이가 크면($\chi^2$ 크면) 기각 → **상단측검정**
- 예: 신상품 $\times$ 성별, $\chi^2=17.12 > \chi^2_{0.05}(2)=5.99$ → 기각(성별과 선호도는 독립이 아니다 = 관련 있다)

### (3) 적합도 검정 vs 독립성 검정 비교
| 구분 | 적합도 검정 | 독립성 검정 |
|---|---|---|
| 목적 | 데이터가 특정 분포를 따르는가 | 두 변수가 관련이 있는가 |
| 비교 | 이론 비율 vs 관측 비율 | 독립 가정 하 기대도수 vs 관측도수 |
| 표 형태 | 1차원 (한 변수) | **2차원 분할표(contingency table)** (두 변수) |
| 자유도 | $k - 1$ | $(r-1)(c-1)$ |
| 공통 | 기대도수 vs 관측도수 차이 → 카이제곱 통계량 → 차이 크면 기각(상단측) | (동일) |

## 3. 강조한 부분 (★ 시험 포인트)

- ★★★ **카이제곱 통계량 기본 틀: $\chi^2 = \sum \dfrac{(\text{관측도수} - \text{기대도수})^2}{\text{기대도수}}$**
- ★★★ **적합도 검정: 자유도 = $k - 1$** (범주 수 − 1)
- ★★★ **독립성 검정: 자유도 = $(r-1)(c-1)$**, 더블 서메이션
- ★★★ **독립성 검정 기대도수 = $\dfrac{(\text{행합}) \times (\text{열합})}{\text{전체 } N}$**
- ★★★ **둘 다 상단측검정** ($\chi^2$이 크면 = 관측·기대 차이가 크면 $H_0$ 기각)
- ★★ 적합도(1차원, 한 변수) vs 독립성(2차원 분할표, 두 변수)

## 4. 특이점 / 기타

- 적합도 검정으로 2범주를 다루면 모비율 검정(정규분포)과 결과가 동일 (범주 2개일 때)
- 멘델의 유전법칙(9:3:3:1) 검증이 적합도 검정의 대표 예
- 독립성 검정의 표를 **분할표(contingency table)**라 부름
- 실무에서는 계산이 복잡해 통계 프로그램(R·파이썬)으로 **p값**을 구하고, p값이 작으면 H₀ 기각 (생성형 AI로 코딩 후 결과 해석이 핵심)
- 재판 비유: 적합도 검정(법인카드 사용비율 진술 검증), 독립성 검정(야근 여부 × 자료 삭제 관련성)

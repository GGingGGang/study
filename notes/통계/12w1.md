# 12주 1강 — 추정 이론: 점추정·추정량·좋은 추정량의 조건

> 통계학 · 추정 (7장)
> 학습내용: 추정의 개념, 점추정/구간추정, 추정량/추정값, 좋은 추정량의 4조건(불편성·유효성·일치성)

---

## 1. 수업 요약

7장 추정(Estimation)을 시작한다. 통계적 추론의 두 축(추정·검정) 중 **추정**(값 추측)을 다루며, **점추정과 구간추정**, **추정량(함수)과 추정값(숫자)**의 구분, 그리고 좋은 추정량이 갖춰야 할 조건인 **불편성·유효성·일치성**을 학습한다.

---

## 2. 개념 정리

### (1) 추정 vs 검정 (통계적 추론)
- 표본으로 모집단 특징을 파악 = **추정(7장) + 검정(8장)**
- **추정** = 값을 추측 ("얼마일까?") → 결과는 **숫자 또는 범위**
- **검정** = 결정·판단 ("맞을까 틀릴까?") → 결과는 참/거짓 판단

### (2) 점추정 vs 구간추정
- **점추정(Point Estimation)**: 모수 $\theta$를 **단일 수치**로 추정 (예: 평균 60점) — 낚시 **바늘**(정확하나 위험)
- **구간추정(Interval Estimation)**: $\theta$가 포함될 **구간**으로 추정 (예: 60~80점) — 낚시 **그물**(안정적)

### (3) 추정량 vs 추정값
- **모수(Parameter) $\theta$**: 모집단 특징(모평균 $\mu$, 모분산 $\sigma^2$, 모비율 $p$) — **모르는 값**
- **추정량(Estimator) $\hat{\theta}$**: 표본의 **함수(함수식, 아직 숫자 아님)**
- **추정값(Estimate)**: 실제 표본 데이터를 대입한 **숫자**
- 예: 항아리 빨간구슬 비율(모수) 모름 → 10개 뽑아 4개 → **$\hat{p}=\dfrac{Y}{n}$(추정량)** → **0.4(추정값)**

### (4) 좋은 추정량의 4조건
1. **불편성(Unbiasedness)**: 추정량의 기댓값 = 모수
2. **유효성(Efficiency)**: 작은 분산
3. **충분성(Sufficiency)**: 이용 가능한 모든 정보 사용 (교양 수준에서 제외, 너무 수학적)
4. **일치성(Consistency)**: 표본이 크면 참값에 근접
→ 본 강의는 **불편성·유효성·일치성** 중심

### (5) 불편성 (Unbiasedness)
- **$E(\hat{\theta})=\theta$** → $\hat{\theta}$는 $\theta$의 **불편추정량(Unbiased Estimator)** (어느 쪽으로도 치우치지 않음)
- 무게중심(평균)만큼은 모수와 같아야 함, **절대적 개념**
- 적용: **$E(\bar{X})=\mu$ → $\bar{X}$는 $\mu$의 불편추정량** / **$E(\hat{p})=p$ → $\hat{p}$는 $p$의 불편추정량** / **$E(S^2)=\sigma^2$ → $S^2$는 $\sigma^2$의 불편추정량**
- ★ **$S^2$를 $n-1$로 나누는 이유 = 불편성을 만족시키기 위해** ($n$으로 나누면 불편성 X)

### (6) 유효성 (Efficiency)
- 불편추정량이 여러 개일 때 **분산이 작은 것이 더 유효(more efficient)**
- **상대적 개념**(비교 대상 필요) ↔ 불편성은 절대적
- 분산이 작을수록 모수에 가까움 → 오차 감소
- **최소분산불편추정량(MVUE)**: 모든 불편추정량 중 분산이 가장 작은 것 (**절대적 개념**, = Best Unbiased Estimator)
- 예: 세 추정량 비교 → 표본평균 $\bar{X}(\hat{\theta}_1)$의 분산이 최소 → 가장 유효 (참고로 $\bar{X}$는 MVUE이기도 함)
- 예: $aT_1+bT_2$가 MVUE 되려면 불편성($a+b=1$) + 분산 최소 → $a=\dfrac{4}{5}$, $b=\dfrac{1}{5}$

### (7) 일치성 (Consistency)
- 표본이 커지면($n\to\infty$) 추정량이 모수의 참값에 같아짐
- **$P(|\hat{\theta}-\theta|<\varepsilon)\to 1$** ($n\to\infty$), $\varepsilon$ = 매우 작은 수
- 확인법 ①: **체비셰프 부등식** ($\bar{X}$, $\hat{p}$, $S^2$ 모두 일치추정량임을 확인)
- 확인법 ②: **$\lim E(\hat{\theta})=\theta$(불편성) + $\lim \operatorname{Var}(\hat{\theta})=0$(분산→0)** → 일치추정량 (더 편한 방법)

---

## 3. 강조한 부분 (★ 시험 포인트)

- ★★★ **좋은 추정량 4조건**: 불편성 · 유효성 · 충분성 · 일치성
- ★★★ **불편성 $E(\hat{\theta})=\theta$** + $\bar{X}$/$\hat{p}$/$S^2$가 각각 $\mu$/$p$/$\sigma^2$의 불편추정량
- ★★★ **$S^2$를 $n-1$로 나누는 이유 = 불편성**
- ★★★ **유효성 = 분산 작은 것**(상대적) / **MVUE = 모든 불편추정량 중 분산 최소**(절대적)
- ★★ **추정량(함수) vs 추정값(숫자)**, 점추정 vs 구간추정
- ★★ 일치성: $n\to\infty$ 시 참값 근접 (체비셰프 부등식 또는 $\lim \operatorname{Var}=0$)

---

## 4. 특이점 / 기타

- 낚시 비유: 점추정 = 바늘(날카로움, 위험), 구간추정 = 그물(안전)
- 다트판 비유: 불편성(중심에 맞나) + 유효성(덜 흔들리나) + 일치성(점점 정확하게) = "중심 + 촘촘 + 점점 정확"
- 충분성은 너무 수학적이라 교양 수준에서 제외
- $\bar{X}$/$\hat{p}$/$S^2$는 모두 불편성·일치성을 만족하는 좋은 추정량

# 9주 2강 — 자연상수 e · 지수분포 · 감마분포

> 통계학 · 확률분포
> 학습내용: 자연상수 e와 지수함수의 특징, 합성함수 미분, 지수분포, 감마분포 소개

---

## 1. 수업 요약

통계에서 자주 쓰이는 **자연상수 e와 지수함수**의 성질을 먼저 정리한 뒤, 포아송 분포와 짝을 이루는 **지수분포**(첫 변화까지 걸리는 시간)를 유도한다. 지수분포의 **메모리리스 성질**(기하분포와 동일)과, 지수분포를 일반화한 **감마분포**까지 다룬다.

---

## 2. 개념 정리

### (1) 자연상수 e와 지수함수
- e = 자연상수 (가장 자연스러운 변화를 나타냄)
- **e^x의 핵심: 미분하면 자기 자신** → 함수값(높이) = 변화속도(기울기)가 항상 같은 **유일한 함수**
- 의미: **현재 상태가 곧 변화의 원인** (인구 많으면 증가 빠름, 돈 많으면 이자 큼, 세포 많으면 분열 많음) → 변화가 자기 자신을 원인으로 삼는 유일한 함수

### (2) 합성함수의 미분
- **(e^(g(x)))′ = g′(x) · e^(g(x))** — 안쪽 g(x)의 변화율을 먼저 곱하고, 지수함수는 자기 자신 그대로
- 예: (e^(2x))′ = 2·e^(2x), (e^(x²))′ = 2x·e^(x²)

### (3) 지수분포 (Exponential Distribution)
- 전제: 단위 구간에 평균 **λ**번 발생하는 **포아송 분포**, X = **첫 번째 사건(변화)이 일어날 때까지 걸리는 시간** (연속형)
- **분포함수 유도**: P(X>x) = P(x까지 변화 없음) = P(N_x=0) = **e^(−λx)** → **F(x) = 1 − e^(−λx)**
- **확률밀도함수: f(x) = F′(x) = λe^(−λx)** (지수함수는 미분해도 자기 자신 + 합성함수 미분)
- λ = 1/θ로 치환 → **f(x) = (1/θ)e^(−x/θ)**, 노테이션 **Γ(1, θ)** ("감마"로 읽음), 모수 θ
- **평균 E(X) = 1/λ = θ** (발생 빈도의 역수 = 평균 대기시간. 예: 1시간 평균 2명 → 평균 대기 30분)
- **분산 Var(X) = 1/λ² = θ²** (평균의 제곱), 표준편차 = θ → **평균 = 표준편차**
- 꼬리가 긴 분포 (사건이 빨리 오면 작은 값, 오래 안 오면 큰 값 → 기다림의 불확실성 반영)
- **P(X>x) = e^(−x/θ)** (위치 암기)
- 활용: 콜센터 통화시간, 은행 서비스시간, 웹서버 응답시간, **부품 수명**(고장까지 시간), 방사성 붕괴, 지진, 자율주행 장애물 감지 → **항상 포아송 분포와 짝** (변화 수 ↔ 변화까지 시간)

### (4) 지수분포의 메모리리스 성질
- **P(X > s+t | X > s) = P(X > t)** : 과거에 얼마나 오래 버텼든(s) 미래 확률은 차이 t에만 의존
- 예: 1000시간 사용한 전구가 100시간 더 버틸 확률 = 새 전구가 100시간 버틸 확률 (전구는 자신이 얼마나 켜져 있었는지 기억 못함)
- **기하분포(이산, 첫 성공까지 시행 횟수) ↔ 지수분포(연속, 첫 변화까지 시간)** — 의미가 같고 이산/연속 차이만 있음

### (5) 감마분포 (Gamma Distribution) — 지수분포의 일반화
- 노테이션 **Γ(α, θ)**, X = **α번째 변화가 일어날 때까지 걸리는 시간**
- X = X₁ + X₂ + … + X_α (각 Xᵢ는 지수분포) → **지수분포를 α번 더한 분포**
- **관계: 지수분포 : 감마분포 = 기하분포 : 음의 이항분포** (특수형 : 일반형)
- **평균 E(X) = αθ, 분산 Var(X) = αθ²** (메모리리스로 독립 → 단순 합)

---

## 3. 강조한 부분 (★ 시험 포인트)

- ★★★ **지수분포: f(x)=λe^(−λx) = (1/θ)e^(−x/θ), F(x)=1−e^(−x/θ)**
- ★★★ **지수분포: E(X)=θ, Var(X)=θ²** (평균=표준편차), P(X>x)=e^(−x/θ)
- ★★★ **지수분포 메모리리스 성질** (연속형에서 이 성질을 갖는 분포)
- ★★ **e^x = 미분하면 자기 자신** + 합성함수 미분 (e^(g(x)))′=g′(x)e^(g(x))
- ★★ **포아송 분포 ↔ 지수분포** 연결 (변화 수 ↔ 변화까지 시간)
- ★ 감마분포 = 지수분포 α번 합, E(X)=αθ, Var=αθ²

---

## 4. 예제 / 특이점

- 예제: 전구 평균수명 1000시간(θ=1000) → 100개 중 1000시간 이상은 e^(−1)×100 ≈ **37개**
- 예제: 학생 시험시간 평균 80분 지수분포 → 9:40 이전 끝낼 확률(성공)을 구하고, 10명 중 "적어도 1명"은 **이항분포**로 (지수+이항 결합 문제)
- 노테이션 Γ(1,θ)의 "감마"는 일반화 분포인 **감마분포 Γ(α,θ)**에서 유래 (기하분포를 NB로 표기한 것과 같은 구조)
- 메모리리스 성질을 갖는 분포: 이산형 = 기하분포 / 연속형 = 지수분포

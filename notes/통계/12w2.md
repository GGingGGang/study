# 12주 2강 — 최대우도추정(MLE)·구간추정·짝비교

> 통계학 · 추정 (7장)
> 학습내용: 최대우도추정(7.2절), 신뢰구간(구간추정), 평균의 구간추정, 짝비교

---

## 1. 수업 요약

점추정의 핵심인 **최대우도추정(MLE)** — 데이터를 가장 잘 설명하는 모수를 찾는 방법 — 을 배운다. 이어 **구간추정(신뢰구간)**으로 넘어가 **평균 μ의 구간추정**(모분산 알 때/모를 때)과 **짝비교(paired comparison)**를 다룬다.

---

## 2. 개념 정리

### (1) 최대우도추정 (MLE, Maximum Likelihood Estimation) — 7.2절
- **피셔(Fisher)**가 만든, 점추정 중 가장 중요한 방법
- **데이터를 가장 그럴듯하게(자연스럽게) 설명하는 모수를 찾는 것**
  - 예: 지하철 도착 간격 데이터(2,4,3,6,5분) → 이 데이터가 가장 자연스러운 평균 간격
  - 예: 용의자 찾기 — 단서(데이터)를 가장 잘 설명하는 용의자(모수)
- **우도(Likelihood)**: 특정 모수가 그 데이터를 발생시킬 확률 = **각 데이터 확률의 곱**
- **우도함수 L(θ) = ∏ f(xᵢ)** (이산형 확률함수 또는 연속형 확률밀도함수의 곱)
- **L(θ)를 최대로 하는 θ̂ = 최우추정량(Maximum Likelihood Estimator, ML)**
- 계산 절차: ① 우도함수 L(θ) 구하기 → ② **로그(ln) 취하기**(곱→합으로 바뀌어 미분 편리, 지수함수의 역함수라 계산 편리, 로그는 증가함수라 결과 동일) → ③ 모수로 미분 → ④ **=0 방정식 풀기**
- 예: 베르누이 분포 → **p̂ = X/n = X̄**(표본비율) / 지수분포 f(x)=(1/θ)e^(−x/θ) → **θ̂ = X̄**(표본평균, 지수분포 평균=θ와 일치)

### (2) 구간추정 (Interval Estimation)
- 모수 θ가 속하는 **구간**을 확률 **1−α**로 찾는 것
- **신뢰구간(Confidence Interval)**, **1−α = 신뢰계수(Confidence Coefficient)**, **α = 오차율**
- 100(1−α)% 신뢰구간 = 신뢰하한(왼쪽) ~ 신뢰상한(오른쪽)
- 의미: 95% 신뢰구간 = 동일 추정을 100번 하면 95번은 모수 참값을 포함, 5번은 벗어남

### (3) 평균 μ에 대한 구간추정 (3가지 경우)
- **경우 ① 모분산 σ² 알 때**: X̄ 표준화 → 표준정규분포 → **Z_(α/2)** 이용
  - P(−Z_(α/2) < (X̄−μ)/(σ/√n) < Z_(α/2)) = 1−α → μ만 남기고 정리 → 신뢰하한/상한 (예: 95% → Z=1.96)
- **경우 ② 모분산 모름 + 표본 큼**: CLT + σ를 S로 대체 → 표준정규분포(Z_(α/2))
- **경우 ③ 모분산 모름 + 표본 작음(n<30)**: σ를 S로 대체 → **t분포(자유도 n−1)** → **t_(α/2)(n−1)** 이용 (t분포는 소표본에도 사용 가능)
- ※ **공식 암기보다 "패턴(원리)"를 기억**: 표준정규/t분포를 가운데 놓고 대칭성으로 양 끝점을 찾아 μ만 남기고 부등식 정리

### (4) 짝비교 (Paired Comparison) — 짝을 이루는 두 모평균의 차
- **동일 대상의 실험 전/후를 비교** (예: 교육 전후 작업능률, 강의 전후 성적)
- 핵심 관찰값: **차이 Dᵢ = Xᵢ − Yᵢ** (순서 유지하며 계산)
- μ_D = μ_X − μ_Y, S_D² = Dᵢ의 표본분산
- σ_D를 모르므로 **t분포(자유도 n−1)** 사용 → D̄, S_D 계산 → μ_D만 남기고 구간추정

---

## 3. 강조한 부분 (★ 시험 포인트)

- ★★★ **최대우도추정(MLE)** 절차: 우도함수 L(θ)=∏f(xᵢ) → 로그(ln) → 모수로 미분 → =0 방정식
- ★★ MLE 예: 베르누이 → p̂=X/n, 지수분포 → θ̂=X̄
- ★★★ **신뢰구간 1−α(신뢰계수), α(오차율)**, 의미(100번 중 95번 포함)
- ★★★ **평균 구간추정 3경우**: ①σ² 앎→Z / ②σ² 모름·대표본→Z(CLT) / ③σ² 모름·소표본→t(n−1)
- ★★ **짝비교**: 차이 Dᵢ로 t분포 구간추정 (실험 전/후 동일 대상)
- ★ 공식보다 패턴(대칭성으로 양 끝점 찾아 μ만 남기기) 기억

---

## 4. 특이점 / 기타

- MLE는 피셔가 창시한 통계학 핵심 이론 (ML = 누구나 아는 약자)
- 로그를 취하는 이유: 곱→합 변환(미분 편리) + 지수함수의 역함수(계산 편리)
- 신뢰구간 공식은 외우기보다 "표준정규/t분포 대칭성 → μ만 남기고 부등식 정리" 원리로 기억
- 짝비교(paired comparison)는 실험 전/후 동일 대상 비교에 쓰이며 검정에서도 활용

# 11주 2강 — 카이제곱 분포(S²의 분포)·통계량 정리·t분포

> 통계학 · 표본론 (6장)
> 학습내용: 카이제곱 분포의 핵심 성질(S²의 분포), 자유도, 통계량 3종 정리, t분포, X̄ 분포 종합

---

## 1. 수업 요약

카이제곱 분포의 가장 중요한 성질인 **(n−1)S²/σ² ~ χ²(n−1)** 을 유도하고, 그 과정에서 **자유도**의 의미를 이해한다. 이어 통계량 3종(X̄·p̂·S²)의 평균·분산을 종합 정리하고, 모분산을 모를 때 쓰는 **t분포**와 **X̄의 분포 4가지 경우**를 마무리한다.

---

## 2. 개념 정리

### (1) 카이제곱 분포의 핵심 성질 — S²의 분포
- 출발: **Σ((Xᵢ−μ)/σ)² ~ χ²(n)** (자유도 n)
- Xᵢ−μ = (Xᵢ−X̄) + (X̄−μ)로 분해 후 전개 → 교차항이 0
- 결과: Σ((Xᵢ−μ)/σ)² = Σ((Xᵢ−X̄)/σ)² + ((X̄−μ)/(σ/√n))²
- 우변 둘째 항 = ((X̄−μ)/(σ/√n))² ~ χ²(1) → χ²(n) = χ²(?) + χ²(1) → 첫 항 = **χ²(n−1)**
- **∴ (n−1)S²/σ² ~ χ²(n−1)** (= Σ((Xᵢ−X̄)/σ)²)
- 핵심 비교: **μ를 쓰면 χ²(n), X̄를 쓰면 χ²(n−1)** (자유도가 1 감소)

### (2) 자유도 (Degree of Freedom)
- μ 대신 X̄로 대체하면 자유도가 1 감소하는 이유 = **제약조건** 때문
- 예: X̄=10(제약)이면 X₁이 정해지면 X₂는 자유가 없음 → 자유도 1 / n개 표본 + 제약 1개 → **자유도 n−1**

### (3) (n−1)S²/σ² ~ χ²(n−1) 활용
- **분산(S²)에 관련된 모든 문제는 카이제곱 분포로 풂**
- 예: 강철빔 11개, S²>205 확률 → (11−1)S²/σ² ~ χ²(10)
- **E(S²) = σ²** (카이제곱 평균 = 자유도 이용), **Var(S²) = 2σ⁴/(n−1)** (카이제곱 분산 = 2×자유도)

### (4) 통계량 3종 평균·분산 종합
| 통계량 | 평균 | 분산 |
|---|---|---|
| 표본평균 X̄ | **μ**(모평균) | **σ²/n** |
| 표본비율 p̂ | **p**(모비율) | **p(1−p)/n** |
| 표본분산 S² | **σ²**(모분산) | **2σ⁴/(n−1)** |
- 공통점: 평균 = 모수, **분산의 분모에 n 관련** → n이 커지면 분산↓

### (5) t분포 (Student's t-distribution)
- 배경: **(X̄−μ)/(σ/√n) ~ N(0,1)** 인데, 실제로는 **모분산 σ²를 모르는 경우가 많음** → σ 대신 **표본표준편차 S**로 대체
- σ를 S로 대체하면 표준정규분포가 아니라 **(X̄−μ)/(S/√n) ~ t(n−1)** (자유도 n−1, 자유도 1 감소)
- 유래: **고셋(Gosset)**이 기네스 맥주회사 품질관리(소표본)를 위해 개발, 필명 **"스튜던트"** 사용 → 스튜던트 t분포
- 평균 0(0 중심 대칭), **분산 n/(n−2) > 1**(표준정규보다 큼 → **꼬리가 두꺼움**, 불확실성↑), n→∞면 표준정규에 접근
- 표는 카이제곱처럼 **점(분위수) 중심**
- **★ t분포의 매력: 표본이 작아도(소표본) 사용 가능**

### (6) X̄의 분포 — 4가지 경우 종합
| 경우 | 모집단 | σ² | 결과 |
|---|---|---|---|
| ① | 정규 | 알려짐 | **N(0,1)** (표준화) |
| ② | 비정규 | 알려짐 | **근사적 N(0,1)** (CLT) |
| ③ | 정규 | 모름 (S 대체) | **t(n−1)** — **소표본에도 성립!** |
| ④ | 비정규 | 모름 (S 대체) | **근사적 N(0,1)** (CLT) |
- ①②④는 정규분포, **③만 t분포** (소표본에도 성립하는 것이 핵심)

---

## 3. 강조한 부분 (★ 시험 포인트)

- ★★★ **(n−1)S²/σ² ~ χ²(n−1)** (S²의 분포) + μ→χ²(n), X̄→χ²(n−1) (자유도 1 감소)
- ★★★ **통계량 3종**: X̄(μ, σ²/n) / p̂(p, p(1−p)/n) / S²(σ², 2σ⁴/(n−1))
- ★★★ **(X̄−μ)/(S/√n) ~ t(n−1)** (모분산 모를 때, σ→S 대체)
- ★★★ **t분포는 소표본에도 사용 가능** + X̄의 4가지 경우 (③만 t분포)
- ★★ E(S²)=σ², Var(S²)=2σ⁴/(n−1) / 자유도 = 제약조건 하 독립 정보 개수

---

## 4. 특이점 / 기타

- 카이제곱 분포가 통계적 추론(추정·검정)에서 중요한 이유가 바로 이 4번째 성질(S²의 분포)
- t분포 유래: 고셋이 기네스 맥주회사 비밀 유지를 위해 필명 "스튜던트" 사용
- t분포는 표준정규보다 꼬리가 두꺼움(분산이 큼) → 불확실성 반영
- 표본이 충분히 크면(n→∞) t분포도 CLT에 의해 정규분포로 접근 → 큰 자유도는 표에 거의 없음

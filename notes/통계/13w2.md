# 13주 2강 — 가설검정의 원리: 오류·유의수준·검정력·p값

> 통계학 · 가설검정 (8장)
> 학습내용: 제1종/제2종 오류, 유의수준, 검정력, 가설검정 5단계, 단측/양측검정, p값

---

## 1. 수업 요약

가설검정의 핵심 원리를 재판 비유로 다룬다. **두 종류의 오류(제1종·제2종)**와 그 확률(**유의수준 α, 검정력**), **가설검정 5단계**, **단측/양측검정**, 그리고 실무에서 가장 많이 쓰는 **p값(유의확률)**을 학습한다.

---

## 2. 개념 정리

### (1) 가설검정의 두 오류
- **제1종 오류(Type I Error)**: 귀무가설이 참인데 **기각** (무죄를 유죄로) → 더 심각하게 봄(엄격한 기준)
- **제2종 오류(Type II Error)**: 귀무가설이 거짓인데 **채택** (유죄를 무죄로, 증거 부족)
- 두 오류는 **상반** (하나가 커지면 다른 하나는 작아짐)

### (2) 확률 개념
- **제1종 오류 확률 = α** (H₀ 참인데 기각할 확률)
- **제2종 오류 확률 = β** (H₀ 거짓인데 채택할 확률)
- **유의수준(Significance Level) α = 제1종 오류를 범할 확률의 최대 허용한계** (많이 쓰는 값: 0.01, 0.05, 0.1)
- **검정력 함수(Power Function) γ(μ) = 거짓인 H₀를 제대로 기각할 확률 = 1 − β(μ)**, 그 값을 **검정력(Power)**이라 함
- 재판 비유: α = 억울한 유죄를 허용하는 최대 한계 (예: 5%까지만 감수)

### (3) 가설검정 5단계 (재판 비유)
1. **가설 설정** (귀무가설 H₀ / 대립가설 H₁)
2. **검정통계량 계산** (증거 점수 = 수상함의 강도)
3. **유의수준 결정** (판결 기준)
4. **기각역 설정** (유죄 구역)
5. **최종 판결** (기각역 안 → 기각 / 밖 → 채택)

### (4) 검정의 종류 (기각역 위치)
- **상단측검정(Upper)**: H₁: μ > μ₀ → **오른쪽** 기각역
- **하단측검정(Lower)**: H₁: μ < μ₀ → **왼쪽** 기각역
- **양측검정(Two-sided)**: H₁: μ ≠ μ₀ → **양쪽** 기각역 (같으냐 다르냐)
- 분류: 단측(상/하단측) vs 양측

### (5) α와 β 계산
- **α**: μ=μ₀(H₀ 참)이라는 가정 하에서 기각할 확률 (μ가 하나로 고정)
- **β(μ)**: H₀가 거짓(μ≠μ₀)이라는 가정 하에서 채택할 확률 → μ≠μ₀는 값이 많으므로 **μ의 함수**
- **검정력 함수 γ(μ) = 1 − β(μ)**
- α↑ → β↓ (상반), **표본 수↑ → α·β 동시에 감소**

### (6) p값 (P-value, 유의확률) ★ 실무 핵심
- **귀무가설을 기각할 수 있는 가장 작은 유의수준**
- 의미: **H₀가 참(무죄)이라는 전제 하에서, 관측된 것만큼 극단적인 증거가 나올 확률**
- **p값이 크면** = 흔함, 이상하지 않음 → **H₀ 기각 못함**(무죄)
- **p값이 작으면** = 드묾, 매우 이상함(우연으로 보기 어려움) → **H₀ 기각**(유죄)
- **판정: p값 < α → 기각 / p값 > α → 채택** (p값이 작을수록 H₀ 기각 가능성↑)
- 컴퓨터 통계 프로그램(R 등)은 **p값만 알려주고** 최종 판단은 사람이 유의수준과 비교해서 결정

---

## 3. 강조한 부분 (★ 시험 포인트)

- ★★★ **제1종 오류(α, 더 심각) vs 제2종 오류(β)** + 두 오류는 상반
- ★★★ **유의수준 α = 제1종 오류를 범할 확률의 최대 허용한계**
- ★★★ **상단측 / 하단측 / 양측 검정** (기각역의 위치)
- ★★★ **p값 = 기각 가능한 최소 유의수준**, **p값 < α → H₀ 기각**
- ★★ **검정력 = 1 − β** (거짓 H₀를 제대로 기각), 검정력 함수는 μ의 함수
- ★★ **표본 수↑ → α·β 동시 감소** / 가설검정 5단계

---

## 4. 특이점 / 예제

- 재판 비유: 가설검정 = 무죄(H₀)를 가정한 뒤 그것이 얼마나 버티기 힘든지 따지는 과정
- 제1종 오류(억울한 유죄)를 제2종보다 더 심각하게 봄 → 보통 α를 먼저 고정하고 β를 낮춤
- 예제: 상단측, X̄=11.4, μ₀=10, σ²=16, n=25 → Z=1.75 → **p값=0.0401** → α=0.01이면 채택, α=0.05이면 기각
- R 같은 통계 프로그램은 "기각/채택"을 직접 말하지 않고 p값만 출력 → "유의확률이 작으니 의미 있는 검정 = H₀ 기각"
- 대립가설이 점(예: H₀: μ=10 vs H₁: μ=11) 형태여도 동일하게 검정 가능(상단측으로 처리)

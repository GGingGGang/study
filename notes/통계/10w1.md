# 10주 1강 — 정규분포 (Normal Distribution)

> 통계학 · 확률분포
> 학습내용: 정규분포의 중요성, 정의, 표준정규분포, 표준화, 확률 계산

---

## 1. 수업 요약

통계학에서 **가장 중요한 분포인 정규분포**를 다룬다. 정규분포가 중요한 이유(많은 자연·사회 현상, **중심극한정리**, 통계 추론의 기초), **68-95-99.7 법칙**, 정의와 모수, **표준정규분포와 표준화(Z점수)**, 그리고 표준정규분포표를 이용한 확률 계산을 학습한다.

---

## 2. 개념 정리

### (1) 정규분포가 중요한 이유
- **Normal = 평범한/가장 정상적인** (반대 = abnormal 이상한) → 이름부터 가장 정상적인 분포
- 많은 자연·사회 현상이 정규분포를 따름 (키·몸무게·지능지수·오차·시험성적·제품규격 오차) → 평균 중심으로 모임
- **중심극한정리(Central Limit Theorem)**: **어떤 분포든(이산형 포함) 표본 크기가 커지면 표본평균들의 분포가 정규분포에 가까워짐** → 매우 파격적 (통계학의 핵심)
- 통계적 추론·가설검정 대부분이 정규분포를 가정해 만들어짐

### (2) 68-95-99.7 법칙
- **$\mu \pm 1\sigma$ → 68.2%** / **$\mu \pm 2\sigma$ → 95.4%** / **$\mu \pm 3\sigma$ → 99.7%**
- 예: 평균 70, 표준편차 10에서 80점 $= +1\sigma$ → 상위 약 15.9%($=100-50-34.1$)

### (3) 정규분포의 정의
- 확률밀도함수 **$f(x) = \dfrac{1}{\sqrt{2\pi}\,\sigma}\cdot \exp\!\left(-\dfrac{(x-\mu)^2}{2\sigma^2}\right)$** (암기 불필요), 가우스가 만들어 **가우스 분포**라고도 함
- **모수 2개: $\mu$(평균), $\sigma^2$(분산)** → 노테이션 **$N(\mu, \sigma^2)$** (확률밀도함수만 알면 평균·분산을 바로 알 수 있음 → 편리)

### (4) 표준정규분포 (Standard Normal Distribution)
- **$\mu=0, \sigma^2=1$로 고정**한 가장 간단한 정규분포 → **$N(0, 1)$**
- 분포함수는 고유 기호 **$\Phi$(파이)** 사용 (다른 분포의 $F$ 대신)
- exp 표기: $e^x$를 $\exp(x)$로 풀어 씀

### (5) 정규분포의 그래프 특징
- **완벽한 대칭(symmetric)**, **종모양(bell-shaped)**
- $x=\mu$에서 최대 → **평균 = 최빈값 = 중앙값 = $\mu$**
- 전체 면적=1, $\mu$ 기준 좌우 0.5씩
- **변곡점: $x = \mu \pm \sigma$** (참고), $x = \mu \pm 3\sigma$에서 $x$축(점근선)에 거의 접함
- $\mu$가 다르면 중심 위치가 다름 / $\sigma$가 다르면 퍼진 정도(폭)가 다름

### (6) 표준화 (Standardization)
- **$Z = \dfrac{X - \mu}{\sigma}$** = 표준화된 확률변수($Z$점수) → 평균 0, 분산 1 = **상대적 위치 척도**
- 단위가 다른 데이터 비교에 사용 (예: 여러 나라 월급을 Z점수로 환산 → 가장 높은 사람 비교)
- **일반 정규분포를 표준정규분포로 변환**

### (7) 확률 계산 (표준정규분포표 이용)
- 정규분포 f(x)가 복잡해 직접 적분이 어려움 → **표준화 후 표준정규분포표** 사용
- 예: $N(75, 9)$에서 80점 이상 → $Z=\dfrac{80-75}{3}=1.67$ → $P(Z\ge 1.67)=1-\Phi(1.67)=1-0.9525=$ **0.0475**
- 표는 **왼쪽 누적확률 $\Phi$**를 제공, **음수 점은 없음** → 대칭성을 이용해 양수로 변환($\Phi(-x)=1-\Phi(x)$)
- 역문제(점 찾기): $P(X\ge x_0)=0.33$ → $\Phi(z)=0.67$ → $z=0.44$ → $x_0=74.4$

### (8) $P(|X-\mu| \le k\sigma)$ 와 체비셰프 비교
- 표준화 → $P(|Z| \le k)$: $k=1$ → 0.6826, $k=2$ → 0.9544, $k=3$ → 0.9973 (= 68-95-99.7 법칙)
- **체비셰프 부등식**(분포 가정 없이 근사) vs **정규분포**(분포 가정 → 정확한 값)

### (9) 정규분포의 성질 (선형성)
- $X$가 정규분포 → **$aX+b$도 정규분포** (평균 $a\mu+b$, 분산 $a^2\sigma^2$)
- 독립인 정규분포들의 선형결합 $\sum(a_iX_i+b_i)$도 **정규분포** (평균$=\sum(a_i\mu_i+b_i)$, 분산$=\sum a_i^2\sigma_i^2$)

---

## 3. 강조한 부분 (★ 시험 포인트)

- ★★★ **정규분포 $N(\mu, \sigma^2)$**: 모수 = 평균 $\mu$, 분산 $\sigma^2$
- ★★★ **중심극한정리**: 표본평균은 표본 크기↑ 시 정규분포에 근접 (이산형 포함)
- ★★★ **표준화 $Z=\dfrac{X-\mu}{\sigma}$ → 표준정규분포 $N(0,1)$**, 분포함수 기호 $\Phi$
- ★★★ **68-95-99.7 법칙** ($1\sigma$·$2\sigma$·$3\sigma$)
- ★★ 표준정규분포표 이용법 (왼쪽 누적 Φ, 음수는 대칭성으로 변환)
- ★★ 정규분포의 선형변환·선형결합도 정규분포

---

## 4. 특이점 / 기타

- Normal(정상) ↔ abnormal(이상)의 어원으로 중요성을 강조
- 가우스가 만들어 "가우스 분포"
- 표준정규분포는 모수가 없어 표를 만들기 편함 → 모든 정규분포 문제를 표준화로 해결
- 음수 점에 대한 확률은 항상 양수로 바꿔 풀고, 그림을 그려 확인하는 습관 권장
- 체비셰프 부등식(근사)과 달리 정규분포 가정 시 정확한 확률 계산 가능

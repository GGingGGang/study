# 14주 1강 — 모평균·비율·분산의 가설검정 + 짝비교 검정

> 통계학 · 가설검정 (8장)
> 학습내용: 모평균 검정(Z검정/t검정), 짝비교 검정, 비율 검정, 모분산 검정

---

## 1. 수업 요약

가설검정의 실제 적용을 다룬다. 구간추정과 동일한 순서로 **모평균 검정**(모분산 알 때 Z검정 / 모를 때 t검정), **짝비교 검정**, **모비율 검정**(소표본 이항 / 대표본 정규), **모분산 검정**(카이제곱)을 학습한다. 검정통계량을 구해 기각역과 비교하는 패턴이 일정하다.

---

## 2. 개념 정리

### (1) 모평균 $\mu$ 검정 — 3가지 풀이 방식
1. **고전적 방식**: $\bar{X}$의 기각역($C_1, C_2$)을 구해 $\bar{X}$와 비교 (이해 쉬움)
2. **검정통계량 직접 비교**: 검정통계량 값을 임계값과 비교 (이론적으로 가장 편함 → 주로 사용)
3. **p값 방식**: p값 < 유의수준 $\alpha$ → 기각 (컴퓨터·통계자료에서 많이 사용)

- **경우 ① $\sigma^2$ 알 때 → 정규분포검정(Z검정)**: 검정통계량 **$Z=\dfrac{\bar{X}-\mu_0}{\sigma/\sqrt{n}}$**
  - 상단측: $Z > Z_\alpha$ / 하단측: $Z < -Z_\alpha$ / 양측: $|Z| > Z_{\alpha/2}$ → 기각
- **경우 ② $\sigma^2$ 모름 → t분포검정**: 검정통계량 **$T=\dfrac{\bar{X}-\mu_0}{S/\sqrt{n}} \sim t(n-1)$** (사회에서 가장 많이 씀)
  - 단, **표본이 크면 CLT로 정규분포검정**($\sigma$를 $S$로 대체해도 $N(0,1)$)

### (2) 짝비교 검정 (Paired Comparison)
- **동일 대상의 실험 전후 비교** (다이어트 전후, 교육 전후, 혈압약 복용 전후 등)
- 차이 **$D_i = X_i - Y_i$**, $\mu_D = \mu_X - \mu_Y$
- 검정통계량 **$T=\dfrac{\bar{D}}{S_D/\sqrt{n}} \sim t(n-1)$** (T분포 검정)
- ★ **대립가설 $H_1$을 문제대로 조심해서 세울 것** (예: 다이어트 식품이면 "감소" → 단측)

### (3) 모비율 $p$ 검정
- **소표본**: **이항분포 직접** 사용 ($X \sim B(n, p)$, 기각역 $X \ge C$)
  - 이산형이라 $\alpha=0.05$에 **딱 맞는 기각역을 찾기 어려움** → $\alpha$를 넘지 않는 가장 가까운 값으로 설정
- **대표본**: **정규분포검정**(CLT, 표본 30 이상) — 실제 가장 많이 씀
  - 검정통계량 **$Z=\dfrac{\hat{p}-p_0}{\sqrt{p_0(1-p_0)/n}}$**

### (4) 모분산 $\sigma^2$ 검정
- **경우 ① $\mu$ 알 때**: 이론적으로만 다룸(거의 안 씀)
- **경우 ② $\mu$ 모를 때(핵심) → 카이제곱검정**: 검정통계량 **$\dfrac{(n-1)S^2}{\sigma_0^2} \sim \chi^2(n-1)$**
  - 카이제곱은 **비대칭** → 양 끝점을 각각 표시(오른쪽 확률 첨자)
  - 상단측: $\chi^2 > \chi^2_\alpha(n-1)$ / 하단측: $\chi^2 < \chi^2_{1-\alpha}(n-1)$ / 양측: 양쪽

---

## 3. 강조한 부분 (★ 시험 포인트)

- ★★★ **모평균 검정: $\sigma^2$ 알면 Z검정, 모르면 t검정(자유도 $n-1$)**
- ★★★ **모비율 검정: 소표본 = 이항분포, 대표본 = 정규분포(Z)**
- ★★★ **모분산 검정: $\dfrac{(n-1)S^2}{\sigma_0^2} \sim \chi^2(n-1)$** (비대칭 → 양 끝점 각각)
- ★★ **짝비교 검정**: 차이 $D_i$로 t분포 검정, $H_1$ 방향 주의
- ★★ 검정 3방식(고전 / 검정통계량 직접 비교 / p값) — 주로 **검정통계량 직접 비교** 사용
- ★★★ **가설(양측/단측)을 문제대로 정확히 세우기** (반대로 잡으면 결론이 뒤집힘)

---

## 4. 특이점 / 예제

- 가설검정 패턴은 일정: **가설 설정 → 검정통계량 선택(case by case) → 기각역과 비교**
- 표본이 크면 t검정도 CLT에 의해 정규분포검정으로 처리
- 비율 소표본의 이항분포 검정은 이산형이라 유의수준 $\alpha$를 정확히 맞추기 어려워, 보통 표본을 30 이상으로 키워 정규근사 사용
- 예제: 분산 검정 — $\dfrac{(n-1)S^2}{\sigma_0^2} = 27 > \chi^2_{0.025}(9)=19.02$ → $H_0$ 기각 (분산에 차이가 있다)

# 13주 1강 — 비율·분산 구간추정 · 표본크기 결정 · 가설검정 시작

> 통계학 · 추정(7장) → 가설검정(8장)
> 학습내용: 모비율 구간추정, 표본크기 결정, 모분산 구간추정, 가설검정의 기본 원리

---

## 1. 수업 요약

구간추정의 나머지 — **모비율 구간추정**, **표본크기 결정**, **모분산 구간추정(카이제곱)** — 을 마무리하고, 8장 **가설검정**으로 들어가 귀무가설·대립가설·검정통계량·기각역의 개념을 재판 비유로 정리한다.

---

## 2. 개념 정리

### (1) 모비율 p에 대한 구간추정
- p̂의 평균=p, 분산=pq/n (q=1−p) → CLT(표본 큼) → 표준화 → 표준정규분포
- 문제: 분모 pq에 p가 또 있음 → **pq를 p̂q̂로 대체**(p̂가 p의 좋은 추정량)
- P(−Z_(α/2) < (p̂−p)/√(p̂q̂/n) < Z_(α/2)) = 1−α → **p만 남기고 정리** → 신뢰하한/상한
- ★ **비율이므로 신뢰하한이 음수로 나오면 0으로 바꿔줌**

### (2) 표본크기 결정 (오차한계 d 이내)
- **모평균**: **n ≥ (Z_(α/2)·σ/d)²** (σ 알 때) — 예: σ=200, d=40, 95%(Z=1.96) → n≥96.04 → **97개**
- **모비율**: n ≥ (Z_(α/2))²·p̂q̂/d²
  - **p̂ 정보 없으면 p̂=1/2** (p̂(1−p̂) 최댓값 = 1/4) → **n ≥ (Z_(α/2))²/(4d²)**
  - 예(정보 없음): d=0.05, 95% → 385개 / 예(p=0.3 정보 있음): 2090개, 정보 없으면 2401개
  - **정보가 많을수록 필요한 표본 수가 작아짐**

### (3) 모분산 σ²에 대한 구간추정
- **경우 ① 모평균 μ 알 때**: Σ((Xᵢ−μ)/σ)² ~ **χ²(n)** (자유도 n)
- **경우 ② 모평균 μ 모를 때(핵심·실전)**: **(n−1)S²/σ² ~ χ²(n−1)** (자유도 n−1)
- 카이제곱은 **비대칭** → 양 끝점을 각각 표시(오른쪽 확률 기준), χ²_(α/2)(n)와 χ²_(1−α/2)(n)
- σ²이 분모에 있음 → 역수 취하면 부등호 방향이 반대로 → σ²만 남기고 정리 → 신뢰하한/상한
- 정보가 많을수록(μ를 알면) 신뢰구간의 폭이 좁아짐

### (4) 가설검정 (8장) 시작 — 기본 원리
- **가설검정(Hypothesis Testing)**: 표본으로 모수에 대한 가설의 타당성을 판정(결정·판단) → 통계적 추론은 추정+검정으로 완성
- **재판 비유 (무죄추정의 원칙)**:
  - **귀무가설(H₀, Null/영가설)**: 처음 세우는 가설, 거짓이 입증될 때까지 참으로 인정 = **"마음속으로 기각하고 싶은 가설"** (피고인은 무죄)
  - **대립가설(H₁, Alternative)**: H₀를 부정, **"채택되고 싶은·강력한 증거로 입증하고자 하는 가설"** (유죄)
- **기각(Reject) vs 채택(Accept)**: 검정은 대립가설을 직접 증명하는 게 아니라 **H₀가 말이 되는지** 판단 (증거 부족 → H₀ 채택)
- **검정통계량(Test Statistic)** = "판사가 느끼는 수상함의 점수" = 관측된 **증거의 강도** (0 근처면 수상하지 않음, 절댓값 크면 수상함). Z·T·카이제곱 등 case by case
- **기각역(Critical/Rejection Region)** = H₀를 기각하는 영역 = "커트라인", 보통 **양 끝**에 위치 → 검정통계량이 기각역 안이면 기각, 밖이면 채택

---

## 3. 강조한 부분 (★ 시험 포인트)

- ★★★ **모비율 구간추정**: 분모 pq를 p̂q̂로 대체, 신뢰하한 음수면 0
- ★★★ **표본크기 결정**: 모평균 n≥(Zσ/d)², 모비율 정보 없으면 p̂=1/2 → n≥Z²/(4d²)
- ★★★ **모분산 구간추정**: μ 알면 χ²(n), 모르면 **(n−1)S²/σ²~χ²(n−1)** (카이제곱 비대칭 → 양 끝점 각각)
- ★★★ **귀무가설 H₀(기각하고 싶은) vs 대립가설 H₁(입증하고 싶은)**
- ★★★ **검정통계량(증거의 강도) + 기각역(커트라인, 양 끝)**
- ★★ 정보 많을수록 표본 수↓·신뢰구간 폭↓

---

## 4. 특이점 / 기타

- 비율 구간추정에서 신뢰하한이 음수면 비율 특성상 0으로 처리
- p에 대한 사전 정보가 있으면 표본 수가 작아지고, 없으면 p̂=1/2로 가정해 최대 표본 수 산정
- 가설검정은 재판(무죄추정)과 동일한 논리 — "차이가 입증될 때까지 차이는 없다"
- 검정통계량으로는 추정에서 다룬 분포(표준정규·t·카이제곱)를 그대로 사용

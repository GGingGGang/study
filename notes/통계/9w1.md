# 9주 1강 — 기하분포 · 음의 이항분포 · 균등분포

> 통계학 · 확률분포
> 학습내용: 이산형 분포(기하·음의 이항) + 연속형 분포의 시작(균등분포)

---

## 1. 수업 요약

이산형 분포 중 **기하분포**(첫 성공까지의 시행 횟수)와 그 일반화인 **음의 이항분포**(R번째 성공까지의 시행 횟수)를 다루고, 연속형 분포의 첫 주제인 **균등분포**로 넘어간다. 세 분포 모두 베르누이 시행을 기반으로 하며, 기하분포의 **메모리리스 성질**과 균등분포의 **무작위성(객관성)**이 핵심.

---

## 2. 개념 정리

### (1) 기하분포 (Geometric Distribution)
- **세 가지 특징** (베르누이 시행 기반):
  1. 모든 시행은 성공($P=p$) 또는 실패($P=1-p$)
  2. 모든 시행은 독립 → (1+2 = **베르누이 시행**)
  3. 확률변수 **$X$ = 첫 번째 성공까지의 시행 횟수**
- $X$의 값: $1, 2, \ldots, \infty$
- **확률함수: $f(x) = (1-p)^{x-1}\cdot p = q^{x-1}\cdot p$** ($X-1$번 실패 후 마지막에 성공)
- 모수 = **$p$ 하나**, 노테이션 **$NB(1, p)$** (음의 이항분포의 특수형)
- **평균 $E(X) = \dfrac{1}{p}$** (성공확률의 역수) — 예: 동전 앞면 $p=0.5$ → 평균 2번, 불량률 0.01 → 평균 100개
- **분산 $\operatorname{Var}(X) = \dfrac{1-p}{p^2} = \dfrac{q}{p^2}$** — 기다림이 길수록 불확실성↑
- 분포함수: **$P(X>x) = (1-p)^x$**, $P(X\le x) = 1-(1-p)^x$ → 계산에 **무한등비급수(기하급수)** 사용 → "기하분포" 명칭 유래

### (2) 메모리리스 성질 (Memoryless Property) ★ 기하분포의 핵심
- **$P(X>m+n \mid X>m) = P(X>n)$** : 과거에 얼마나 실패했든($m$번) 미래의 성공 확률에는 영향이 없음 → "기억상실"
- 동전은 이전에 무엇을 보여줬는지 전혀 기억하지 못함 (10번 뒷면 나와도 다음 확률 불변)
- **이산형 분포에서 메모리리스 성질을 갖는 유일한 분포 = 기하분포** (연속형에는 지수분포)
- 활용: 첫 계약까지 전화 횟수, AI 로봇이 처음 성공하는 시도 횟수

### (3) 음의 이항분포 (Negative Binomial Distribution = 파스칼 분포)
- **$X$ = R번째 성공까지의 시행 횟수** (기하분포의 일반화, $R=1$이면 기하분포)
- $X$의 값: $R, R+1, R+2, \ldots$
- **확률함수: $f(x) = \binom{x-1}{r-1}\cdot p^{r-1}\cdot q^{x-r}\cdot p$** ($X-1$번 시행에서 $R-1$번 성공 = 이항분포 + 마지막에 반드시 성공 $\times p$)
- 노테이션 **$NB(r, p)$**, **모수 2개($r, p$)** / 이항분포를 일부 이용 → "Negative Binomial"
- **관계: 베르누이:이항 = 기하:음의 이항** (특수형 : 일반형)
- **평균 $E(X) = \dfrac{r}{p}$, 분산 $\operatorname{Var}(X) = \dfrac{r(1-p)}{p^2}$** ($X = X_1+\cdots+X_r$, 각 $X_i$는 기하분포·독립 → 기하분포 평균·분산 $\times r$)
- 활용: 5전 3선승 경기(3번 승리까지 시합 수), 한국시리즈, 합격자 모집, 양품 5개 확보까지 검사, AI 유효 데이터 10개 수집까지

### (4) 균등분포 (Uniform Distribution) — 연속형 분포의 시작
- 구간 $[a, b]$에서 무작위로 점을 찍을 때 **$X$ = 점의 위치** (연속형)
- 기하학적 확률: $P(C\le X\le D) = \dfrac{D-C}{b-a}$, 적분과 일치시키면 → **확률밀도함수 $f(x) = \dfrac{1}{b-a}$** (구간 길이의 역수)
- 노테이션 **$U(a, b)$** (연속형이라 구간 끝점의 등호는 무관)
- **평균 $E(X) = \dfrac{a+b}{2}$** (무게중심 = 가운데)
- **분산 $\operatorname{Var}(X) = \dfrac{(b-a)^2}{12}$**
- **"균등"의 의미**: 같은 길이의 구간은 동일한 확률 → 무작위(랜덤) → **어느 값이 더 자주 나온다는 정보가 없을 때 가장 객관적·합리적인 가정**
- 활용: 버스 대기시간(10분 간격 → $U(0,10)$), 난수 생성($U(0,1)$, 치우치지 않음), 센서 측정 오차($U(-0.5, 0.5)$)

---

## 3. 강조한 부분 (★ 시험 포인트)

- ★★★ **기하분포 메모리리스 성질** + **이산형에서 이 성질을 갖는 유일한 분포 = 기하분포**
- ★★★ **기하분포: $E(X)=\dfrac{1}{p}$, $\operatorname{Var}(X)=\dfrac{1-p}{p^2}$** / 확률함수 $(1-p)^{x-1}p$
- ★★★ **음의 이항분포: $E(X)=\dfrac{r}{p}$, $\operatorname{Var}(X)=\dfrac{r(1-p)}{p^2}$** / $NB(r,p)$, 모수 2개
- ★★ **관계: 베르누이:이항 = 기하:음의 이항** (특수 : 일반)
- ★★ **균등분포: $f(x)=\dfrac{1}{b-a}$, $E(X)=\dfrac{a+b}{2}$, $\operatorname{Var}(X)=\dfrac{(b-a)^2}{12}$**
- ★ $P(X>x)=(1-p)^x$ (기하분포 분포함수 위치 암기)

---

## 4. 특이점 / 기타

- 기하분포는 "첫 성공까지 시행 횟수"($X\ge 1$) 또는 "첫 성공까지 실패 횟수"($X\ge 0$)로 정의 — 둘 다 기하분포(한 칸 shift 차이). 본 수업은 **시행 횟수** 기준
- "기하급수(무한등비급수)"를 이용해 풀어서 **기하분포**라는 이름이 붙음
- 균등분포는 "정보가 없을 때 가장 합리적인 첫 가정"으로 AI/시뮬레이션 난수에 핵심적으로 쓰임

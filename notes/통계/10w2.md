# 10주 2강 — 무작위표본 · 표본평균의 분포 · 중심극한정리

> 통계학 · 표본론
> 학습내용: 무작위표본(IID), 표본평균 $\bar{X}$의 평균·분산, 중심극한정리(CLT), 이항분포의 정규근사, 연속성 수정

---

## 1. 수업 요약

표본론으로 들어가 **무작위표본(IID)** 개념을 정의하고, **표본평균 $\bar{X}$의 분포**(평균 = 모평균, 분산 = 모분산$/n$)를 다룬다. 이어 통계학의 핵심인 **중심극한정리(CLT)** — 어떤 분포든 표본이 커지면 표본평균이 정규분포에 접근 — 를 배우고, 그 응용으로 **이항분포의 정규근사**와 **연속성 수정**을 학습한다.

---

## 2. 개념 정리

### (1) 무작위표본 (Random Sample) = IID
- **독립(Independent) + 동일하게 분포(Identically Distributed) = IID** = 무작위표본
- "동일하게 분포" = 분포뿐 아니라 **모수까지 같음** (첨자가 없음, $\mu$·$\sigma^2$가 모두 동일)
- 표본(sample) = 모집단(population)에서 추출한 단위 (출구조사 비유) → 표본으로 모집단 특징 파악 = 통계적 추론
- 표본이 가져야 할 두 성질: **독립성 + 동일 분포(IID)**

### (2) 표본평균 (Sample Mean) $\bar{X}$
- **$\bar{X} = \dfrac{\sum X_i}{n}$** (산술평균), $\bar{X}$ 자체가 하나의 **확률변수** → 분포를 가짐
- **$\bar{X}$의 평균 = 모평균 $\mu$** (합의 평균 = 평균의 합)
- **$\bar{X}$의 분산 = 모분산$/n$ = $\dfrac{\sigma^2}{n}$** (독립이라 합의 분산 = 분산의 합, $\frac{1}{n}$은 제곱으로 빠져나옴)
- 핵심(언어로 기억): **표본평균의 평균 = 모평균**, **표본평균의 분산 = 모분산 ÷ 표본 개수**
- 정규분포 IID면 **$\bar{X} \sim N(\mu, \sigma^2/n)$** (예: $N(60,36)$ 표본 25개 → $\bar{X} \sim N(60, 36/25=1.2^2)$)

### (3) 중심극한정리 (Central Limit Theorem, CLT)
- **어떤 분포든(분포를 몰라도) IID이고 $n$이 충분히 크면, 표본평균 $\bar{X}$는 정규분포 $N(\mu, \sigma^2/n)$에 접근**
- 표준화: **$\dfrac{\bar{X} - \mu}{\sigma/\sqrt{n}} \to N(0, 1)$** ($n \to \infty$)
- 합 형태: **$\sum X_i \to N(n\mu, n\sigma^2)$**
- 앞 성질과의 차이: **정규분포 가정이 불필요**(어떤 분포라도) + $n$이 커야 한다는 전제
- $n$ 크기 기준: 교과서적 정의는 없지만 **경험적으로 보통 30 이상**
- 파격성: **이산형도 연속형(정규)으로 접근** (균등분포·쌍봉분포·지수분포 모두 표본 크기↑ 시 종모양 대칭으로)

### (4) 이항분포의 정규근사
- 예: 동전 900번 던져 앞면 495번 이상 확률 → 이항분포 직접 계산 불가 → **CLT 사용**
- 앞면 개수 = 이항분포 $B(900, 1/2)$ → **정규근사 $N(\text{평균}=np=450, \text{분산}=npq=225)$** → 표준화 후 표준정규분포표
- **포아송 근사(전제: $n$ 크고 $p\to 0$)** 와 달리 **CLT는 제약이 적음**($n$만 크면 됨, $p=0.5$도 가능)

### (5) 연속성 수정 (Continuity Correction)
- 이산형 → 연속형 전환 시 오차 발생 (이산형은 점, 연속형은 면적 → 한 점의 확률은 연속형에서 0)
- **$X=k$를 $[k-0.5, k+0.5]$ 구간(폭 1)으로 대응** → 왼쪽 하한 $-0.5$, 오른쪽 상한 $+0.5$
- 더 정확한 값을 얻음 (단, 표본이 작을 때 효과가 크고, 표본이 매우 크면 차이가 작음)

---

## 3. 강조한 부분 (★ 시험 포인트)

- ★★★ **무작위표본 = IID** (독립 + 동일 분포, 모수까지 같음)
- ★★★ **$\bar{X}$의 평균 = $\mu$, $\bar{X}$의 분산 = $\dfrac{\sigma^2}{n}$** + 정규 IID → $\bar{X} \sim N(\mu, \sigma^2/n)$
- ★★★ **중심극한정리(CLT)**: 분포 무관, $n$ 크면 $\bar{X} \to N(\mu, \sigma^2/n)$ (이산형도 정규로!)
- ★★ **이항분포의 정규근사**: $B(n,p) \to N(np, npq)$
- ★★ **연속성 수정**: $X=k \to k\pm 0.5$ (이산→연속 변환 시)
- ★ CLT vs 포아송 근사 (제약 조건 차이)

---

## 4. 특이점 / 기타

- 표본평균의 "평균의 평균/평균의 분산"이 어색해 보이지만, $\bar{X}$가 하나의 확률변수이므로 자연스러움
- CLT의 가장 매력적인 점: 태생이 다른 **이산형이 연속형(정규)으로 넘어감**
- "대관람차" 비유: 세상에 존재하는 모든 분포가 결국 표준정규분포로 접근
- 예제: 원에 외접하는 정사각형에 400개 점 → 원 내부 점 개수 = 이항분포 $B(400, \pi/4)$ → CLT로 정규근사

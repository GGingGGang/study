# 11주 1강 — 표본분포 · 통계량 · 표본비율 · 카이제곱 분포

> 통계학 · 표본론 (6장)
> 학습내용: 모수·통계량, 표본평균/표본비율의 분포, 카이제곱 분포

---

## 1. 수업 요약

표본론(6장)으로 들어가, 모집단의 **모수**를 추정하기 위한 **통계량**(표본평균·표본분산·표본비율)과 그 분포(**표본분포**)를 다룬다. 표본평균 X̄와 **표본비율 p̂**의 평균·분산을 정리하고, 표본분산 S²의 분포인 **카이제곱 분포**를 학습한다.

---

## 2. 개념 정리

### (1) 표본론 기본
- 모집단(population)에서 **표본(sample)**을 추출 → 표본으로 모집단의 특징을 파악 (예: 자동차 1만 대 중 100대 안전도 측정)
- 6장 구성: 1절 표본분포 기본 / 2절 **카이제곱 분포** / 3절 **t분포** (모두 표본 관련 분포)
- **모수(Parameter)** = 모집단 특징을 나타내는 숫자: 모평균(μ), 모분산(σ²), 모표준편차(σ), **모비율(p)**

### (2) 통계량 (Statistic) = n개 표본의 함수
- **표본평균 X̄ = (1/n)ΣXᵢ**
- **표본분산 S² = Σ(Xᵢ − X̄)² / (n−1)** ※ n이 아니라 **n−1로 나눔** (이유는 7장 추정에서 설명)
- 표본표준편차 S = √S²
- **표본비율 p̂ = Y/n** (Y = 특정 속성을 가진 개수) — 예: 100명 중 결석 3명 → p̂ = 3/100
- **통계량의 분포 = 표본분포(Sampling Distribution)**

### (3) 표본평균 X̄의 분포 (복습)
- **E(X̄) = μ(모평균), Var(X̄) = σ²/n(모분산÷표본개수)**
- 분모 n의 의미: n이 커지면 분산이 작아짐 → 평균 중심으로 집중 → **오차 감소**(추정·검정에 핵심)
- CLT: n이 커지면 X̄ → 정규분포 (X̄는 1/n 간격이라 연속성 수정 불필요)

### (4) 표본비율 p̂의 분포
- p̂ = Y/n, 여기서 **Y ~ 이항분포 B(n, p)** (성공/실패)
- **E(p̂) = p(모비율), Var(p̂) = p(1−p)/n** (= npq를 n²로 나눈 결과)
- **CLT: n이 크면 p̂ → N(p, p(1−p)/n)** → 표준화로 확률 계산 (n으로 쪼개져 연속성 수정 불필요, 전제 n≥30 정도)

### (5) 카이제곱 분포 (Chi-square Distribution, χ²)
- **표본분산 S²의 분포**를 다루기 위해 만들어진 연속형 분포 (확률밀도함수 복잡·암기 불필요, 감마함수 포함)
- 노테이션 **χ²**(흘림체 대문자 X), 모수 대신 **자유도(degree of freedom)** 사용
  - 자유도 = 제약조건 하에서 자유롭게 정할 수 있는 **독립적 정보의 개수** (정확한 의미는 후반부)
- **평균 E(X) = 자유도(n), 분산 Var(X) = 2×자유도(2n)** ★ 기억
- 그래프: **오른쪽으로 긴 꼬리** (자유도가 커지면 대칭에 가까워짐 — CLT)
- **성질 ①**: 표준정규분포 Z를 제곱 → **Z² ~ χ²(자유도 1)** (일반 정규분포 X → 표준화 Z → Z² ~ χ²(1))
- **성질 ②**: 독립인 카이제곱 분포의 합 → 카이제곱 분포, **자유도 = 자유도들의 합**
- 응용: Xᵢ ~ N(μ, σ²) IID → **Σ((Xᵢ−μ)/σ)² ~ χ²(n)**, 그리고 ((X̄−μ)/(σ/√n))² ~ χ²(1)
- **카이제곱 분포표**: 표 안의 값이 확률이 아니라 **"점(분위수)"**이고, 확률은 표 가로에 제시됨 → 표본 관련 분포는 **확률보다 점이 더 중요**(추정·검정에서)

---

## 3. 강조한 부분 (★ 시험 포인트)

- ★★★ **통계량 3종**: 표본평균 X̄ / 표본분산 S²(**n−1로 나눔**) / 표본비율 p̂
- ★★★ **X̄: E=μ, Var=σ²/n** / **p̂: E=p, Var=p(1−p)/n**
- ★★★ **카이제곱: 평균 = 자유도, 분산 = 2×자유도**
- ★★★ **Z² ~ χ²(1)** (표준정규 제곱 = 자유도 1 카이제곱), 독립 카이제곱 합의 자유도 = 자유도 합
- ★★ 자유도(degree of freedom) 개념, 카이제곱 분포표는 점(분위수) 중심
- ★ 표본분산을 n−1로 나누는 이유는 7장에서

---

## 4. 특이점 / 기타

- 표본분산 S²를 n이 아닌 **n−1**로 나누는 이유는 7장(추정)에서 설명
- 카이제곱·t처럼 표본 관련 분포는 모수 대신 **자유도**를 사용
- 기존 분포표(이항·포아송·정규)는 표 안이 "확률"이었지만, 카이제곱·t 분포표는 표 안이 "점" → 추정·검정에서 점 찾기가 핵심이기 때문
- p̂, X̄는 n으로 잘게 쪼개져 간격이 작으므로 연속성 수정 불필요
- 예제: 4개 N(0,4) IID → Σ(Xᵢ/2)² ~ χ²(4)

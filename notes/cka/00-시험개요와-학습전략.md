## 3. 시험 환경

- PSI Secure Browser로 접속 → **원격 Ubuntu 데스크톱(XFCE)** 환경. 로컬 터미널이 아니라 원격 데스크톱 안의 터미널을 사용한다.
- 브라우저는 원격 데스크톱 안의 Firefox만 사용 가능. 접근 허용 문서:
  - `kubernetes.io/docs`
  - `kubernetes.io/blog`
  - `helm.sh/docs`
- 문제마다 **지정된 kubectl context로 전환**하는 명령이 문제 상단에 제공됨. 반드시 복사–붙여넣기로 전환하고 시작할 것.
- 일부 문제는 특정 노드에 `ssh <node>`로 들어가서 작업. **작업 후 반드시 `exit`로 기본 노드에 복귀**해야 함 (복귀 안 하면 다음 문제를 엉뚱한 노드에서 풀게 됨).
- root 권한이 필요하면 `sudo -i`.
- `k`(=kubectl) alias와 자동완성은 기본 세팅되어 있음. vim/nano 사용 가능.

## 4. 학습 전략

### 4-1. 공부 순서 (이 교과서 기준)
1. **기초 다지기**: 00 → 01(아키텍처) → 02(kubectl)
2. **클러스터 관리**: 03(설치) → 04(업그레이드/etcd백업) → 05(HA) → 06(RBAC) → 07(Helm/Kustomize) → 08(CRD/확장)
3. **워크로드**: 09(Deployment) → 10(ConfigMap/Secret) → 11(스케줄링) → 12(오토스케일링)
4. **네트워킹**: 13(Service) → 14(Ingress/Gateway API) → 15(CoreDNS) → 16(NetworkPolicy)
5. **스토리지**: 17(PV/PVC/StorageClass)
6. **트러블슈팅**: 18(클러스터/노드) → 19(워크로드/네트워크) → 20(모니터링/로깅)
7. **마무리**: 21(치트시트/최종점검)

### 4-2. 실습 환경 만들기
- **killercoda.com/cka**: 무료 브라우저 실습 시나리오
- **kind / minikube**: 로컬 단일 클러스터 (기능 연습용)
- **VM 2~3대 + kubeadm**: 설치/업그레이드/etcd 백업/노드 트러블슈팅 연습에는 이게 필수. Vagrant나 Multipass로 Ubuntu VM을 띄워 직접 클러스터를 구축해볼 것.
- **killer.sh**: 시험 바우처에 포함된 모의시험 2회(세션당 36시간). 실제 시험보다 어렵게 설계되어 있음. **시험 1~2주 전에 반드시 풀어볼 것.**

### 4-3. 핵심 원칙
1. **YAML을 맨손으로 쓰지 마라.** `kubectl create ... --dry-run=client -o yaml > x.yaml`로 뼈대를 생성하고 수정하는 습관을 들일 것.
2. **공식 문서 검색에 익숙해져라.** 시험 중 kubernetes.io/docs 검색 가능. 자주 쓰는 페이지(예: "PersistentVolume", "NetworkPolicy", "kubeadm upgrade")의 예제 YAML 위치를 미리 외워둘 것.
3. **트러블슈팅이 30%다.** kubelet 재시작, static pod 매니페스트 오타 찾기, 노드 NotReady 진단 흐름을 몸에 익힐 것.
4. **시간 관리**: 문제당 평균 6~8분. 배점 낮고 오래 걸리는 문제는 표시(flag)해두고 넘어간 뒤 나중에 돌아올 것.
5. **검증 습관**: 리소스를 만들었으면 `k get`, `k describe`로 실제로 의도대로 됐는지 반드시 확인.

## 5. 접수 절차
1. [training.linuxfoundation.org](https://training.linuxfoundation.org/certification/certified-kubernetes-administrator-cka/)에서 구매 (세일 기간에 30~50% 할인 자주 있음 — 블랙프라이데이, 연말 등)
2. 신분증 이름과 등록 이름 일치 확인 (여권/영문 신분증)
3. PSI 시스템 호환성 체크 (웹캠, 마이크, 네트워크)
4. 시험 예약 — 구매 후 12개월 내

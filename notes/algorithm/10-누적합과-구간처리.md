# 누적합과 구간 처리 (Prefix Sum & Range Techniques)

> 알고리즘 · 자료구조 · 학습내용: 1차원 누적합으로 구간합 O(1) 조회, 2차원 누적합과 포함배제로 직사각형 합 구하기, 차분 배열(imos 기법)로 구간 갱신 O(1), 누적합 + 해시로 "합이 K인 구간 개수" 세기, 구간 곱·XOR 누적, 누적합이 통하지 않는 경우(값이 변할 때)

---

## 1. 1차원 누적합 (Prefix Sum) ★★★

**"i번째부터 j번째까지의 합"을 여러 번 물어보는 문제**에서, 매번 더하면 질의당 O(n)이라 질의가 많으면 O(nq)로 터진다. **미리 앞에서부터의 합을 저장해두면 질의당 O(1)** 이 된다.

`prefix[i]`를 **앞에서 i개의 합**으로 정의하면(즉 `prefix[0] = 0`),

**`sum(l..r) = prefix[r+1] - prefix[l]`**

**앞에 0을 하나 두는 것**이 핵심이다. `l = 0`일 때 인덱스 -1을 신경 쓸 필요가 없어진다.

```python
def build_prefix(arr):
    prefix = [0] * (len(arr) + 1)
    for i, x in enumerate(arr):
        prefix[i + 1] = prefix[i] + x     # 앞에서 i+1개의 합
    return prefix

def range_sum(prefix, l, r):
    """arr[l..r] 합 (양끝 포함, 0-based)"""
    return prefix[r + 1] - prefix[l]

arr = [3, 1, 4, 1, 5, 9, 2, 6]
p = build_prefix(arr)
print(p)                        # [0, 3, 4, 8, 9, 14, 23, 25, 31]
print(range_sum(p, 0, 3))       # 9   (3+1+4+1)
print(range_sum(p, 2, 5))       # 19  (4+1+5+9)
print(range_sum(p, 7, 7))       # 6
print(range_sum(p, 0, 7) == sum(arr))   # True
```

`itertools.accumulate`로 한 줄에 만들 수도 있다.

```python
from itertools import accumulate

arr = [3, 1, 4, 1, 5]
print(list(accumulate(arr)))                 # [3, 4, 8, 9, 14]  (앞에 0 없음)
print(list(accumulate(arr, initial=0)))      # [0, 3, 4, 8, 9, 14]  (3.8+)
```

> ★★★ **핵심**: 누적합의 조건은 **역연산이 있어야 한다**는 것이다. 덧셈은 뺄셈이 있어서 되고, XOR는 자기 자신이 역연산이라 된다. **최댓값·최솟값은 역연산이 없어 누적으로 구간 질의를 못 한다**(그래서 세그먼트 트리나 희소 테이블이 필요하다).

> **함정**: 문제 입력이 **1-based**(1번째~n번째)인 경우가 많다. 인덱스 오프셋을 헷갈리면 한 칸씩 어긋난다. **입력을 1-based로 받으면 `prefix[i] = prefix[i-1] + arr[i]`로 두고 `sum(l..r) = prefix[r] - prefix[l-1]`** 로 통일하는 게 실수가 적다.

```python
def build_prefix_1based(arr):
    """arr는 1-based (arr[0]은 더미)"""
    n = len(arr) - 1
    p = [0] * (n + 1)
    for i in range(1, n + 1):
        p[i] = p[i - 1] + arr[i]
    return p

arr1 = [0, 3, 1, 4, 1, 5]          # 인덱스 1부터 실제 데이터
p1 = build_prefix_1based(arr1)
print(p1[4] - p1[1])               # 1..? -> arr[2..4] = 1+4+1 = 6
```

## 2. 2차원 누적합 (2D Prefix Sum) ★★

격자에서 **직사각형 영역의 합**을 O(1)에 구한다. `P[i][j]`를 **(1,1)부터 (i,j)까지의 합**으로 정의하고, **포함배제(inclusion-exclusion)** 로 만든다.

**`P[i][j] = grid[i][j] + P[i-1][j] + P[i][j-1] - P[i-1][j-1]`**

두 번 더해진 왼쪽 위 영역을 **한 번 빼준다**는 뜻이다. 질의도 같은 원리다.

**`sum(r1,c1 ~ r2,c2) = P[r2][c2] - P[r1-1][c2] - P[r2][c1-1] + P[r1-1][c1-1]`**

```python
def build_prefix_2d(grid):
    n, m = len(grid), len(grid[0])
    P = [[0] * (m + 1) for _ in range(n + 1)]   # 0행/0열을 패딩으로 둔다
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            P[i][j] = (grid[i - 1][j - 1]
                       + P[i - 1][j] + P[i][j - 1]
                       - P[i - 1][j - 1])       # 겹친 부분 한 번 제거
    return P

def rect_sum(P, r1, c1, r2, c2):
    """0-based 좌표 (r1,c1)~(r2,c2) 직사각형 합"""
    r1, c1, r2, c2 = r1 + 1, c1 + 1, r2 + 1, c2 + 1
    return P[r2][c2] - P[r1 - 1][c2] - P[r2][c1 - 1] + P[r1 - 1][c1 - 1]

grid = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
]
P = build_prefix_2d(grid)
print(rect_sum(P, 0, 0, 2, 2))    # 45 (전체)
print(rect_sum(P, 1, 1, 2, 2))    # 28 (5+6+8+9)
print(rect_sum(P, 0, 0, 0, 2))    # 6  (첫 행)
print(rect_sum(P, 2, 2, 2, 2))    # 9  (한 칸)
```

> **함정**: 패딩 없이 `P`를 n×m으로 만들면 `i-1`, `j-1`이 **-1이 되어 파이썬에서는 에러 없이 맨 뒤 원소를 참조**한다. 조용히 틀린 답이 나오므로 **반드시 (n+1)×(m+1)로 패딩**한다.

## 3. 차분 배열 / imos 기법 (Difference Array) ★★★

누적합의 **반대 방향** 기법이다. **"구간 [l, r]에 v를 더하라"는 갱신이 여러 번 들어오고, 마지막에 최종 배열만 필요할 때** 쓴다. 갱신마다 구간을 순회하면 O(nq)지만, **차분 배열에 양 끝 두 칸만 건드리면 갱신이 O(1)** 이고 마지막에 한 번 누적합을 취하면 끝난다. 전체 **O(n + q)**.

원리는 간단하다. `diff[l] += v`, `diff[r+1] -= v` 로 두면, 누적합을 취했을 때 **l부터 r까지만 v가 더해진다.**

```python
def apply_ranges(n, updates):
    """updates: (l, r, v) 목록. 0-based, 양끝 포함"""
    diff = [0] * (n + 1)          # r+1 접근을 위해 한 칸 여유
    for l, r, v in updates:
        diff[l] += v              # 여기서부터 +v
        diff[r + 1] -= v          # 여기서부터 원복
    res, cur = [], 0
    for i in range(n):
        cur += diff[i]            # 누적합이 최종 값
        res.append(cur)
    return res

print(apply_ranges(6, [(0, 2, 1), (1, 4, 2), (3, 5, -1)]))
# [1, 3, 3, 1, 1, -1]
```

2차원으로도 확장된다. **네 모서리에 부호를 번갈아 찍고** 행·열 방향으로 각각 누적합을 취한다.

```python
def apply_ranges_2d(n, m, updates):
    """updates: (r1, c1, r2, c2, v) 0-based, 양끝 포함"""
    diff = [[0] * (m + 1) for _ in range(n + 1)]
    for r1, c1, r2, c2, v in updates:
        diff[r1][c1] += v
        diff[r1][c2 + 1] -= v
        diff[r2 + 1][c1] -= v
        diff[r2 + 1][c2 + 1] += v      # 두 번 뺀 부분 복구
    # 행 방향 누적
    for i in range(n):
        for j in range(1, m):
            diff[i][j] += diff[i][j - 1]
    # 열 방향 누적
    for j in range(m):
        for i in range(1, n):
            diff[i][j] += diff[i - 1][j]
    return [row[:m] for row in diff[:n]]

for row in apply_ranges_2d(4, 4, [(0, 0, 1, 1, 1), (1, 1, 3, 3, 2)]):
    print(row)
# [1, 1, 0, 0]
# [1, 3, 2, 2]
# [0, 2, 2, 2]
# [0, 2, 2, 2]
```

> ★★★ **핵심**: **"구간 갱신이 여러 번, 조회는 마지막에 한 번"이면 차분 배열**, **"갱신은 없고 구간 조회가 여러 번"이면 누적합**이다. 둘 다 있으면 세그먼트 트리(또는 펜윅 트리)로 넘어가야 한다.

> **함정**: `diff[r + 1]`을 위해 배열을 **n+1 크기로** 잡아야 한다. n 크기로 잡으면 마지막 구간 갱신에서 `IndexError`가 나거나, `diff[-1]`처럼 엉뚱한 곳을 건드리게 된다.

## 4. 누적합 + 해시 — 합이 K인 구간 개수 ★★★

**"연속 부분 수열의 합이 정확히 K인 경우의 수"** 는 투 포인터로는 음수가 있으면 안 되지만, **누적합과 해시를 결합하면 음수가 있어도 O(n)** 에 풀린다.

`prefix[j] - prefix[i] == K` 이므로, **각 j에 대해 `prefix[j] - K` 값이 앞에서 몇 번 나왔는지**를 세면 된다.

```python
from collections import defaultdict

def count_subarrays_sum_k(arr, k):
    cnt = defaultdict(int)
    cnt[0] = 1              # 빈 접두사(합 0)를 미리 하나 넣어둔다
    cur, ans = 0, 0
    for x in arr:
        cur += x
        ans += cnt[cur - k] # 이전 접두사 중 cur-k 인 개수만큼 구간이 생긴다
        cnt[cur] += 1
    return ans

print(count_subarrays_sum_k([1, 2, 3], 3))            # 2  ([1,2], [3])
print(count_subarrays_sum_k([1, -1, 0], 0))           # 3
print(count_subarrays_sum_k([3, 4, 7, 2, -3, 1, 4, 2], 7))   # 4
print(count_subarrays_sum_k([1, 1, 1], 2))            # 2
```

> **함정**: **`cnt[0] = 1` 초기화를 빼먹으면** "배열 맨 앞부터 시작하는 구간"을 세지 못해 답이 작게 나온다. 접두사 합 자체가 K인 경우가 여기에 해당한다.

**K의 배수인 구간 개수**도 같은 골격이다. 값 대신 **나머지**를 센다.

```python
from collections import defaultdict

def count_subarrays_divisible(arr, k):
    cnt = defaultdict(int)
    cnt[0] = 1
    cur, ans = 0, 0
    for x in arr:
        cur = (cur + x) % k      # 파이썬 %는 음수에도 0 이상 결과를 준다
        ans += cnt[cur]          # 나머지가 같은 두 접두사 사이 구간은 k의 배수
        cnt[cur] += 1
    return ans

print(count_subarrays_divisible([4, 5, 0, -2, -3, 1], 5))   # 7
print(count_subarrays_divisible([1, 2, 3], 3))              # 3
```

**나머지가 같은 두 접두사 사이 구간의 합은 K의 배수**라는 사실이 핵심이다.

## 5. 구간 곱과 구간 XOR ★★

**XOR는 자기 자신이 역연산**(`a ^ a == 0`)이라 누적이 아주 잘 맞는다. 뺄셈 자리에 XOR를 그대로 쓰면 된다.

```python
def build_xor_prefix(arr):
    p = [0] * (len(arr) + 1)
    for i, x in enumerate(arr):
        p[i + 1] = p[i] ^ x
    return p

def range_xor(p, l, r):
    return p[r + 1] ^ p[l]      # 뺄셈 대신 XOR

arr = [3, 8, 2, 6, 4]
p = build_xor_prefix(arr)
print(range_xor(p, 0, 4), 3 ^ 8 ^ 2 ^ 6 ^ 4)   # 같은 값
print(range_xor(p, 1, 3), 8 ^ 2 ^ 6)           # 같은 값
```

**곱은 조심해야 한다.** 나눗셈이 역연산이지만 **0이 하나라도 있으면 복원할 수 없고**, 모듈러 연산에서는 나눗셈 대신 **모듈러 역원**이 필요하다(소수 모듈러일 때 페르마 소정리 사용).

```python
MOD = 1_000_000_007

def build_mul_prefix(arr):
    p = [1] * (len(arr) + 1)
    for i, x in enumerate(arr):
        p[i + 1] = p[i] * x % MOD
    return p

def range_mul(p, l, r):
    # 나눗셈 대신 모듈러 역원: a^(MOD-2) (MOD가 소수일 때)
    return p[r + 1] * pow(p[l], MOD - 2, MOD) % MOD

arr = [2, 3, 5, 7]
p = build_mul_prefix(arr)
print(range_mul(p, 1, 3), 3 * 5 * 7 % MOD)     # 105 105
print(range_mul(p, 0, 3), 2 * 3 * 5 * 7)       # 210 210
```

> **함정**: 위 방식은 **배열에 0이 없을 때만** 유효하다. 0이 섞이면 `pow(0, MOD-2, MOD)`가 0이 되어 값이 깨진다. **0의 개수를 따로 누적**해서 "구간에 0이 있으면 답은 0"으로 처리하거나, 세그먼트 트리를 쓴다.

| 연산 | 누적합으로 구간 질의 가능? | 이유 |
|---|---|---|
| 합 | O | 뺄셈이 역연산 |
| XOR | O | 자기 자신이 역연산 |
| 곱 | 조건부 | 0·모듈러 역원 문제 |
| 최댓값·최솟값 | **X** | 역연산 없음 |
| GCD | **X** | 역연산 없음 |

## 6. 누적합이 통하지 않는 경우 ★★

누적합은 **원본 배열이 변하지 않을 때만** 유효하다. `arr[i]`가 하나 바뀌면 **그 뒤의 모든 누적합이 틀어져 재계산에 O(n)** 이 든다.

| 상황 | 갱신 | 구간 합 조회 | 적절한 도구 |
|---|---|---|---|
| 값이 안 변함, 조회 많음 | — | O(1) | **누적합** |
| 구간 갱신 많음, 조회는 마지막 한 번 | O(1) | 마지막에 O(n) | **차분 배열(imos)** |
| 점 갱신 + 구간 조회가 섞여서 많음 | O(log n) | O(log n) | **펜윅 트리 / 세그먼트 트리** |
| 구간 갱신 + 구간 조회가 섞여서 많음 | O(log n) | O(log n) | **레이지 세그먼트 트리** |

```python
arr = [1, 2, 3, 4]
prefix = [0]
for x in arr:
    prefix.append(prefix[-1] + x)
print(prefix)                # [0, 1, 3, 6, 10]

arr[1] = 100                 # 값 하나만 바뀌어도
print(prefix[3] - prefix[1]) # 5  <- 옛 값 기준이라 틀림
print(sum(arr[1:3]))         # 103 <- 실제 값
# 고치려면 prefix를 인덱스 1부터 전부 다시 계산해야 한다 -> O(n)
```

> ★★★ **핵심**: **갱신이 섞이는 순간 누적합은 답이 아니다.** "값이 바뀐다 + 구간 합을 물어본다"가 동시에 보이면 **펜윅 트리(Binary Indexed Tree)나 세그먼트 트리**로 넘어가는 것이 정석이며, 이는 플래티넘 구간의 핵심 자료구조다.

## 7. 실전에서 자주 엮이는 패턴 ★★

**부분합의 최댓값**(카데인)은 누적합의 사고와 이어진다. `prefix[j] - min(prefix[i])`를 최대화하는 문제로 볼 수 있다.

```python
def max_subarray_sum(arr):
    """연속 부분 수열의 최대 합 (원소를 최소 1개 포함)"""
    best = cur = arr[0]
    for x in arr[1:]:
        cur = max(x, cur + x)     # 이어붙일지, 여기서 새로 시작할지
        best = max(best, cur)
    return best

print(max_subarray_sum([-2, 1, -3, 4, -1, 2, 1, -5, 4]))   # 6
print(max_subarray_sum([-5, -2, -8]))                      # -2
```

**2차원 최대 부분 직사각형 합**도 같은 재료로 푼다. **위·아래 행 구간을 고정한 뒤 열별 합을 누적**해 1차원 배열로 만들고, 거기에 위 카데인을 적용하면 O(n²m)이다.

### 한 줄 요약
누적합은 **앞에서부터의 합을 미리 저장해 구간 합 질의를 O(1)** 로 만드는 기법이고, 배열 앞에 0을 하나 패딩하면 경계 처리가 깔끔해지며 2차원에서는 **포함배제**로 확장된다. 반대로 **구간 갱신이 많고 조회는 마지막에 한 번**이면 차분 배열(imos)로 양 끝 두 칸만 건드려 갱신을 O(1)에 처리하고 마지막에 누적합을 한 번 취하면 된다. 누적합과 해시를 결합하면 "합이 K인 구간 개수"나 "K의 배수인 구간 개수"를 **음수가 있어도 O(n)** 에 셀 수 있는데, 이때 `cnt[0] = 1` 초기화가 정답을 가른다. 누적 기법은 **역연산이 있는 연산(합·XOR)에만** 쓸 수 있고 **원본이 변하면 무너지므로**, 갱신과 조회가 섞이면 펜윅 트리나 세그먼트 트리로 넘어가야 한다.

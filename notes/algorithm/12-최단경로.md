# 최단 경로 (Shortest Path)

> 알고리즘 · 그래프 · 학습내용: 최단경로 알고리즘 4종 비교(BFS·다익스트라·벨만포드·플로이드워셜), heapq 다익스트라와 방문 처리 최적화, prev 배열 경로 복원, 벨만-포드와 음수 사이클 탐지, 플로이드-워셜의 k-i-j 루프 순서, 0-1 BFS, float('inf') 초기화와 도달 불가 처리

---

## 1. 네 알고리즘 비교 ★★★

| 알고리즘 | 시간 복잡도 | 음수 가중치 | 출발점 | 용도 |
|----------|-------------|-------------|--------|------|
| **BFS** | `O(V + E)` | 불가 (**가중치 자체가 없어야**) | 1개 | 가중치 없는 그래프·격자 최단 거리 |
| **0-1 BFS** | `O(V + E)` | 불가 (가중치가 0/1) | 1개 | 벽 부수기, 방향 전환 비용 |
| **다익스트라** | `O(E log V)` | **불가** | 1개 | 양수 가중치 최단 경로 (실전 1순위) |
| **벨만-포드** | `O(V · E)` | **가능** | 1개 | 음수 간선 존재 · **음수 사이클 탐지** |
| **플로이드-워셜** | `O(V³)` | 가능 (음수 사이클은 X) | **모든 쌍** | `V ≤ 400~500`에서 모든 쌍 거리 |

> ★★★ **핵심**: 선택은 두 가지 질문으로 끝난다. **(1) 가중치가 있나?** 없으면 BFS, 0/1이면 0-1 BFS. **(2) 음수 간선이 있나?** 없으면 다익스트라, 있으면 벨만-포드. 그리고 **"모든 쌍"**을 물으면서 `V`가 400 이하면 플로이드-워셜이다.

**다익스트라가 음수를 못 다루는 이유**는 그리디 전제 때문이다. "지금 큐에서 꺼낸 가장 가까운 정점은 더 이상 짧아질 수 없다"고 확정해버리는데, 음수 간선이 있으면 나중에 돌아와서 더 짧아질 수 있어 그 전제가 깨진다.

## 2. 다익스트라 + 우선순위 큐 ★★★

```python
import heapq

INF = float('inf')
n = 6
graph = [[] for _ in range(n + 1)]
for a, b, w in [(1,2,2),(1,3,5),(1,4,1),(2,3,3),(2,4,2),
                (3,2,3),(3,6,5),(4,3,3),(4,5,1),(5,3,1),(5,6,2)]:
    graph[a].append((b, w))

def dijkstra(start):
    dist = [INF] * (n + 1)
    dist[start] = 0
    pq = [(0, start)]                   # (거리, 정점) — 거리를 앞에 둬야 거리로 정렬된다
    while pq:
        d, now = heapq.heappop(pq)
        if dist[now] < d:               # ★ 이미 더 짧게 확정된 정점이면 버린다
            continue
        for nxt, w in graph[now]:
            nd = d + w
            if nd < dist[nxt]:          # 더 짧아질 때만 갱신하고 큐에 넣는다
                dist[nxt] = nd
                heapq.heappush(pq, (nd, nxt))
    return dist

dijkstra(1)[1:]                         # [0, 2, 3, 1, 2, 4]
```

**`heapq`는 최소 힙**이고 튜플은 앞 원소부터 비교하므로, `(거리, 정점)` 순서로 넣어야 가장 가까운 정점이 먼저 나온다. `(정점, 거리)`로 넣는 실수가 잦은데 그러면 그냥 번호 순 탐색이 된다.

### 방문 처리 최적화 — `if dist[now] < d: continue` ★★★

> ★★★ **핵심**: 이 두 줄이 다익스트라 성능의 전부다. 이 구현은 `visited` 배열을 쓰지 않고, **같은 정점을 여러 번 큐에 넣되 꺼낼 때 낡은 항목을 버리는(lazy deletion)** 방식이다. `dist[now]`는 항상 최신 최솟값이므로, 꺼낸 `d`가 그보다 크면 이미 더 좋은 경로로 처리를 끝냈다는 뜻이라 안전하게 건너뛸 수 있다.

이 줄이 없어도 **정답은 나오지만**, 낡은 항목마다 이웃을 전부 다시 훑기 때문에 최악의 경우 지수적으로 느려져 시간 초과가 난다. 반대로 `visited` 배열을 따로 쓰는 구현도 맞지만, 위 방식이 짧고 실수가 적다.

> **함정**: `if nd < dist[nxt]` 검사 없이 무조건 `heappush`하면 큐가 폭발한다. **갱신에 성공한 경우에만 큐에 넣는다.**

## 3. 경로 복원 (prev 배열) ★★

거리뿐 아니라 "어떤 경로로 갔는지"를 물으면 **직전 정점을 기록**한다.

```python
import heapq
INF = float('inf')

def dijkstra_path(start, end):
    dist = [INF] * (n + 1)
    prev = [0] * (n + 1)                # prev[v] = v로 오기 직전 정점
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        cur, now = heapq.heappop(pq)
        if dist[now] < cur:
            continue
        for nxt, w in graph[now]:
            nd = cur + w
            if nd < dist[nxt]:
                dist[nxt] = nd
                prev[nxt] = now         # 갱신하는 그 순간에 같이 기록
                heapq.heappush(pq, (nd, nxt))
    if dist[end] == INF:
        return INF, []                  # 도달 불가
    path, v = [], end
    while v:                            # 도착점에서 거꾸로 타고 올라간다
        path.append(v)
        v = prev[v]
    return dist[end], path[::-1]        # 뒤집어야 출발→도착 순서

dijkstra_path(1, 6)                     # (4, [1, 4, 5, 6])
```

`prev`를 0으로 초기화하고 시작점의 `prev`도 0이므로, `while v:`가 시작점에서 자연스럽게 멈춘다(1-indexed라 0은 정점이 아니다). 경로 복원은 **거리 갱신과 동시에** 기록해야지, 나중에 거리 배열만 보고 역추적하면 간선이 여러 개일 때 틀린다.

## 4. 벨만-포드 (음수 간선·음수 사이클) ★★

```python
INF = float('inf')

def bellman_ford(n, edges, start):
    dist = [INF] * (n + 1)
    dist[start] = 0
    for i in range(n):                  # n-1번 완화 + n번째는 음수 사이클 검사
        updated = False
        for a, b, w in edges:
            if dist[a] != INF and dist[a] + w < dist[b]:
                dist[b] = dist[a] + w
                updated = True
                if i == n - 1:          # n번째에도 갱신되면 음수 사이클
                    return None
        if not updated:                 # 조기 종료 (더 줄어들 게 없음)
            break
    return dist

bellman_ford(4, [(1,2,4),(1,3,3),(2,3,-2),(3,4,2)], 1)   # [inf, 0, 4, 2, 4]
bellman_ford(3, [(1,2,1),(2,3,-3),(3,2,1)], 1)           # None (음수 사이클)
```

**왜 `V-1`번인가**: 사이클이 없는 최단 경로는 간선을 최대 `V-1`개 쓴다. 매 라운드마다 최소 한 정점의 최단 거리가 확정되므로 `V-1`번이면 충분하다. **`V`번째 라운드에서도 거리가 줄어든다면 무한히 줄일 수 있다는 뜻**이고, 그게 곧 음수 사이클이다.

> **함정**: `if dist[a] != INF` 검사를 빼면 안 된다. 파이썬에서 `float('inf') + (-5)`는 여전히 `inf`라 에러는 안 나지만, **아직 도달하지 못한 정점에서 출발하는 가짜 완화**가 일어나 없는 음수 사이클을 있다고 판정하거나 거리가 오염된다.

여기서 탐지되는 건 **시작점에서 도달 가능한** 음수 사이클뿐이다. 그래프 어딘가에 있는 사이클을 전부 찾으려면 `dist`를 전부 0으로 초기화해 모든 정점에서 동시에 출발시킨다.

## 5. 플로이드-워셜과 k-i-j 순서 ★★★

```python
INF = float('inf')
V = 4
g = [[INF] * (V + 1) for _ in range(V + 1)]
for i in range(1, V + 1):
    g[i][i] = 0                         # 자기 자신은 0
for a, b, w in [(1,2,5),(1,4,8),(2,3,2),(3,4,1),(4,1,2)]:
    g[a][b] = min(g[a][b], w)           # 중복 간선은 최솟값만 남긴다

for k in range(1, V + 1):               # ★ 경유지 k가 반드시 가장 바깥
    for i in range(1, V + 1):
        if g[i][k] == INF:              # 가지치기 (없어도 정답, 있으면 빠름)
            continue
        for j in range(1, V + 1):
            if g[i][k] + g[k][j] < g[i][j]:
                g[i][j] = g[i][k] + g[k][j]

# g[1][1:] == [0, 5, 7, 8]
# g[2][1:] == [5, 0, 2, 3]
```

### 왜 k가 바깥이어야 하나 ★★★

점화식은 `D_k[i][j] = min(D_{k-1}[i][j], D_{k-1}[i][k] + D_{k-1}[k][j])`, 즉 **"1..k번 정점만 경유지로 허용했을 때의 최단 거리"**를 `k`를 늘려가며 확장하는 DP다. `k`가 바깥에 있어야 `k`단계 계산이 시작될 때 `k-1`단계가 **완전히** 끝나 있다.

`i`나 `j`를 바깥에 두면 `g[i][k]`나 `g[k][j]`가 아직 갱신되지 않은 채로 참조되어 경유 경로를 놓친다. 위와 똑같은 그래프에 `i-j-k` 순서를 쓰면 실제로 이렇게 갈린다.

| 값 | 정답 (k-i-j) | 잘못된 순서 (i-j-k) |
|----|--------------|---------------------|
| `g[1][3]` | 7 | 7 (우연히 맞음) |
| **`g[2][1]`** | **5** (2→3→4→1) | **INF** (경로를 놓침) |

> ★★★ **핵심**: **`for k` → `for i` → `for j`.** 우연히 몇 개가 맞아서 더 위험하다. 일부만 틀리므로 작은 예제로는 잘 안 잡히고 채점에서 틀린다. 순서를 통째로 외운다.

**초기화 순서도 함정이다.** `g[i][i] = 0`을 간선 입력보다 **먼저** 해야 한다. 나중에 하면 자기 자신으로 가는 음수 또는 양수 자기 루프 간선을 0으로 덮어버린다. (자기 루프를 활용하는 문제라면 반대로 나중에 하면 안 된다.)

## 6. 0-1 BFS ★★

가중치가 **0과 1 두 종류뿐**일 때, 다익스트라의 `log` 없이 `O(V + E)`로 끝낸다.

```python
from collections import deque
INF = float('inf')

board = [
    "0100",
    "1101",
    "0000",
    "1110",
]
N, M = len(board), len(board[0])
dx = (-1, 1, 0, 0)
dy = (0, 0, -1, 1)

dist = [[INF] * M for _ in range(N)]
dist[0][0] = 0
dq = deque([(0, 0)])
while dq:
    x, y = dq.popleft()
    for k in range(4):
        nx, ny = x + dx[k], y + dy[k]
        if not (0 <= nx < N and 0 <= ny < M):
            continue
        cost = 1 if board[nx][ny] == '1' else 0     # 벽을 부수면 1, 빈 칸이면 0
        if dist[x][y] + cost < dist[nx][ny]:
            dist[nx][ny] = dist[x][y] + cost
            if cost == 0:
                dq.appendleft((nx, ny))             # 가중치 0 → 덱 앞에
            else:
                dq.append((nx, ny))                 # 가중치 1 → 덱 뒤에
# dist[N-1][M-1] == 1  (벽 한 번만 부수면 도달)
```

**원리**: 덱 안의 거리값은 항상 `d`와 `d+1` 두 종류만 섞여 있고, 앞쪽이 항상 작다. 그래서 덱이 우선순위 큐 역할을 그대로 하면서 `heappush/heappop`의 `log V`가 사라진다.

> **함정**: 0-1 BFS도 **꺼낼 때 방문 확정이 아니라 거리 비교(`if dist[x][y] + cost < dist[nx][ny]`)로 갱신**해야 한다. 일반 BFS처럼 `visited` 하나로 처리하면 나중에 더 짧은 경로가 와도 반영되지 않아 틀린다.

가중치가 0/1이 아니라 0/`W` 두 종류여도 같은 논리가 성립한다. 세 종류 이상이면 다익스트라로 돌아가야 한다.

## 7. `float('inf')` 초기화와 도달 불가 ★★

```python
import heapq
INF = float('inf')

iso = [[] for _ in range(4)]
iso[1].append((2, 3))                   # 3번 정점은 어디서도 닿을 수 없다
dd = [INF] * 4
dd[1] = 0
pq = [(0, 1)]
while pq:
    c, u = heapq.heappop(pq)
    if dd[u] < c:
        continue
    for v, w in iso[u]:
        if c + w < dd[v]:
            dd[v] = c + w
            heapq.heappush(pq, (dd[v], v))

[('INF' if x == INF else x) for x in dd[1:]]    # [0, 3, 'INF']
```

| 초기값 | 장점 | 주의점 |
|--------|------|--------|
| `float('inf')` | 어떤 정수보다 크다는 게 보장됨. 오버플로 없음 | 출력 전에 반드시 별도 문자열로 바꿔야 함 |
| `int(1e9)` | 정수라 출력·연산이 편함 | 경로 합이 이 값을 넘으면 조용히 틀림 |
| `-1` | 미방문 표시로 직관적 | `min` 갱신 로직과 안 맞아 조건문이 지저분해짐 |

> **함정**: 파이썬 정수는 무제한이라 오버플로가 없지만, **`INF`를 `int(1e9)` 같은 작은 값으로 잡으면 "간선 최대 비용 × 정점 수"가 그걸 넘어 도달 불가와 실제 거리가 구분되지 않는다.** 가중치가 크면 `float('inf')`를 쓰거나 `INF`를 넉넉히(예: `10**18`) 잡는다.

**출력할 때 `inf`를 그대로 `print`하면 `inf`라는 문자열이 찍혀 오답이 된다.** 문제가 요구하는 표기(`INFINITY`, `-1`, `0` 등)로 반드시 변환한다.

```python
print('\n'.join('INF' if d == INF else str(d) for d in dd[1:]))
```

## 8. 자주 나오는 변형 패턴 ★★

| 패턴 | 접근 |
|------|------|
| 특정 정점을 **반드시 경유** | `d(S,X) + d(X,E)` — 다익스트라 여러 번 |
| **역방향** 거리 (모두 → 하나) | 간선을 뒤집은 그래프에서 다익스트라 |
| 상태가 추가됨 (벽 K번 부수기) | `dist[정점][사용횟수]`로 **차원을 늘린다** |
| 간선이 아니라 **정점에 비용** | 도착 정점 비용을 간선 가중치로 옮긴다 |
| 최단 경로가 **여러 개**일 때 개수 | 거리 갱신 시 `cnt[nxt] = cnt[now]`, 같으면 `+=` |
| 경로 위 **최대 간선 최소화** | 완화식을 `max(d, w)`로 바꾼 다익스트라 |

**상태 확장이 플래티넘 구간의 핵심 도구다.** "기름을 K번 넣을 수 있다", "벽을 M번 부술 수 있다" 같은 조건은 그래프를 `정점 × 상태` 크기로 늘려 그 위에서 평범한 다익스트라/BFS를 돌리면 된다.

### 한 줄 요약
최단 경로는 **가중치 유무와 음수 유무 두 질문으로 알고리즘이 결정된다**. 실전 주력은 **`heapq` 다익스트라이고 `if dist[now] < d: continue` 한 줄이 성능을 좌우**한다. **음수 간선이면 벨만-포드로 `V`번째 갱신을 보고 음수 사이클을 잡고**, **모든 쌍이면 플로이드-워셜을 반드시 `k-i-j` 순서로** 돌린다. 도달 불가는 `float('inf')`로 두되 **출력 직전에 반드시 변환**한다.

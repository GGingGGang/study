# 정렬 (Sorting)

> 알고리즘 · 자료구조 · 학습내용: 파이썬 `sort`/`sorted`가 쓰는 Timsort와 안정 정렬의 의미, `key` 함수와 다중 기준 정렬, 버블·선택·삽입 정렬 개념, 병합 정렬(분할정복)과 퀵 정렬(피벗·최악 O(n²)), 계수 정렬·기수 정렬, 정렬 알고리즘 비교표, 좌표 압축

---

## 1. sort 와 sorted ★★★

| 구분 | `list.sort()` | `sorted(iterable)` |
|---|---|---|
| 대상 | 리스트 전용 | 모든 이터러블 |
| 동작 | **제자리(in-place) 정렬** | **새 리스트 반환** |
| 반환값 | `None` | 정렬된 `list` |
| 메모리 | 추가 메모리 적음 | 원본 크기만큼 추가 |

```python
a = [3, 1, 2]
print(a.sort())            # None  <- 반환값이 없다!
print(a)                   # [1, 2, 3]

b = (3, 1, 2)
print(sorted(b))           # [1, 2, 3] (튜플을 넣어도 list가 나온다)
print(sorted("cab"))       # ['a', 'b', 'c']
print(sorted([3, 1, 2], reverse=True))   # [3, 2, 1]
```

> **함정**: `arr = arr.sort()` 는 `arr`를 `None`으로 만든다. 가장 흔한 실수다. **제자리 정렬은 `arr.sort()`, 새 리스트가 필요하면 `arr = sorted(arr)`.**

## 2. Timsort — 파이썬의 정렬 알고리즘 ★★★

파이썬의 정렬은 **Timsort**다. **병합 정렬 + 삽입 정렬의 하이브리드**로, 이미 정렬된 구간(**run**)을 찾아 활용하기 때문에 **부분적으로 정렬된 데이터에서 매우 빠르다.**

| 항목 | Timsort |
|---|---|
| 평균 / 최악 | **O(n log n)** |
| 최선 | **O(n)** (이미 정렬돼 있을 때) |
| 공간 | O(n) |
| **안정성** | **안정(stable)** |

**안정 정렬(stable sort)** 은 **값이 같은 원소들의 원래 순서가 정렬 후에도 유지된다**는 뜻이다.

```python
data = [("b", 2), ("a", 1), ("c", 2), ("d", 1)]
print(sorted(data, key=lambda x: x[1]))
# [('a', 1), ('d', 1), ('b', 2), ('c', 2)]
# 값이 1인 a와 d, 값이 2인 b와 c의 상대 순서가 원본 그대로 유지됨
```

> ★★★ **핵심**: 안정성 덕분에 **"여러 번 정렬해서 다중 기준"** 을 만들 수 있다. **가장 덜 중요한 기준부터 차례로 정렬**하면 최종적으로 원하는 우선순위가 완성된다.

```python
people = [("kim", 30, 170), ("lee", 25, 180), ("park", 30, 165)]

# 1순위 나이 오름차순, 2순위 키 내림차순 -> 덜 중요한 키부터 정렬
tmp = sorted(people, key=lambda p: p[2], reverse=True)   # 2순위 먼저
tmp = sorted(tmp, key=lambda p: p[1])                    # 1순위 나중
print(tmp)   # [('lee', 25, 180), ('kim', 30, 170), ('park', 30, 165)]
```

## 3. key 함수 활용 ★★★

**한 번에 다중 기준을 주려면 `key`가 튜플을 반환**하게 한다. 튜플은 앞 원소부터 순서대로 비교된다.

```python
words = ["banana", "kiwi", "apple", "fig", "date"]

# 길이 오름차순, 같으면 사전순
print(sorted(words, key=lambda w: (len(w), w)))
# ['fig', 'kiwi', 'date', 'apple', 'banana']

people = [("kim", 30), ("lee", 25), ("park", 30)]
# 나이 내림차순, 같으면 이름 오름차순 -> 숫자는 음수로 뒤집는다
print(sorted(people, key=lambda p: (-p[1], p[0])))
# [('kim', 30), ('park', 30), ('lee', 25)]
```

> **함정**: **문자열은 `-`로 뒤집을 수 없다.** 숫자 기준은 `-x`로 내림차순을 만들 수 있지만, 문자열 기준을 내림차순으로 섞어야 하면 **`reverse=True`로 통째로 뒤집거나, 안정성을 이용해 두 번에 나눠 정렬**한다.

`operator.itemgetter`는 `lambda`보다 조금 빠르다(C로 구현).

```python
from operator import itemgetter

rows = [("kim", 30, "A"), ("lee", 25, "B"), ("park", 30, "C")]
print(sorted(rows, key=itemgetter(1)))          # 인덱스 1 기준
print(sorted(rows, key=itemgetter(1, 0)))       # 다중 기준
print(sorted(rows, key=itemgetter(1), reverse=True))
```

**입력 자체를 정렬 기준에 맞게 읽어두는 것**도 중요하다. 문자열로 읽은 숫자는 사전순으로 정렬되므로 결과가 달라진다.

```python
nums = ["10", "9", "100"]
print(sorted(nums))                 # ['10', '100', '9']  <- 문자열 사전순
print(sorted(nums, key=int))        # ['9', '10', '100']  <- 숫자 기준
```

## 4. 직접 구현하는 O(n²) 정렬 3종 ★

실전에서 쓸 일은 거의 없지만 **면접 단골**이라 개념은 알아야 한다.

| 알고리즘 | 아이디어 | 시간 | 안정성 |
|---|---|---|---|
| **버블 정렬** | 인접한 두 개를 비교·교환하며 큰 값을 뒤로 밀어냄 | O(n²) | 안정 |
| **선택 정렬** | 남은 구간에서 **최솟값을 골라** 앞에 배치 | O(n²) | 불안정 |
| **삽입 정렬** | 앞쪽 정렬된 구간에 현재 원소를 **끼워 넣음** | O(n²), 거의 정렬된 입력엔 O(n) | 안정 |

```python
def bubble_sort(arr):
    a = arr[:]
    n = len(a)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):          # 뒤쪽 i개는 이미 확정
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                swapped = True
        if not swapped:                     # 한 바퀴 교환이 없으면 이미 정렬됨
            break
    return a

def selection_sort(arr):
    a = arr[:]
    for i in range(len(a)):
        m = i
        for j in range(i + 1, len(a)):      # 남은 구간의 최솟값 위치
            if a[j] < a[m]:
                m = j
        a[i], a[m] = a[m], a[i]
    return a

def insertion_sort(arr):
    a = arr[:]
    for i in range(1, len(a)):
        key, j = a[i], i - 1
        while j >= 0 and a[j] > key:        # 자리를 찾을 때까지 뒤로 민다
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key
    return a

src = [5, 2, 9, 1, 5, 6]
print(bubble_sort(src), selection_sort(src), insertion_sort(src))
```

**삽입 정렬만은 실용적 가치가 있다.** 거의 정렬된 데이터에서 O(n)에 가깝고, 그래서 Timsort도 작은 조각을 삽입 정렬로 처리한다.

## 5. 병합 정렬 (Merge Sort) ★★

**분할정복(divide and conquer)**: 반으로 쪼개 각각 정렬한 뒤, **정렬된 두 리스트를 합친다(merge)**. **항상 O(n log n)** 이고 **안정**이지만 O(n) 추가 메모리를 쓴다.

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])        # 왼쪽 정렬
    right = merge_sort(arr[mid:])       # 오른쪽 정렬
    return merge(left, right)

def merge(left, right):
    res = []
    i = j = 0
    while i < len(left) and j < len(right):
        # <= 로 비교해야 같은 값의 원래 순서가 보존된다 (안정성)
        if left[i] <= right[j]:
            res.append(left[i]); i += 1
        else:
            res.append(right[j]); j += 1
    res.extend(left[i:])
    res.extend(right[j:])
    return res

print(merge_sort([5, 2, 9, 1, 5, 6]))   # [1, 2, 5, 5, 6, 9]
```

병합 과정을 살짝 고치면 **역순 쌍(inversion) 개수**를 셀 수 있다. 오른쪽 원소가 먼저 나올 때 **왼쪽에 남아 있는 개수만큼 역순 쌍**이 생긴다.

```python
def count_inversions(arr):
    def sort_count(a):
        if len(a) <= 1:
            return a, 0
        mid = len(a) // 2
        left, cl = sort_count(a[:mid])
        right, cr = sort_count(a[mid:])
        merged, i, j, cnt = [], 0, 0, cl + cr
        while i < len(left) and j < len(right):
            if left[i] <= right[j]:
                merged.append(left[i]); i += 1
            else:
                merged.append(right[j]); j += 1
                cnt += len(left) - i      # 왼쪽 남은 전부가 역순 쌍
        merged.extend(left[i:]); merged.extend(right[j:])
        return merged, cnt
    return sort_count(arr)[1]

print(count_inversions([2, 4, 1, 3, 5]))   # 3
print(count_inversions([3, 2, 1]))         # 3
```

## 6. 퀵 정렬 (Quick Sort) ★★

**피벗(pivot)** 을 하나 골라 **작은 값 / 같은 값 / 큰 값** 으로 나누고 재귀한다. 평균 O(n log n)에 상수가 작아 실전에서 빠르지만, **피벗을 계속 나쁘게 고르면(이미 정렬된 배열에서 맨 앞을 피벗으로) 최악 O(n²)** 다.

```python
import random

def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = random.choice(arr)          # 무작위 피벗으로 최악 케이스 회피
    less = [x for x in arr if x < pivot]
    equal = [x for x in arr if x == pivot]
    greater = [x for x in arr if x > pivot]
    return quick_sort(less) + equal + quick_sort(greater)

print(quick_sort([5, 2, 9, 1, 5, 6]))   # [1, 2, 5, 5, 6, 9]
print(quick_sort(list(range(10))[::-1]))
```

같은 분할 아이디어로 **k번째 작은 수를 평균 O(n)** 에 찾는 **퀵 셀렉트**가 나온다.

```python
import random

def quick_select(arr, k):
    """k는 0-based: 정렬했을 때 k번째 원소"""
    if len(arr) == 1:
        return arr[0]
    pivot = random.choice(arr)
    less = [x for x in arr if x < pivot]
    equal = [x for x in arr if x == pivot]
    greater = [x for x in arr if x > pivot]
    if k < len(less):
        return quick_select(less, k)
    if k < len(less) + len(equal):
        return pivot                     # 피벗 구간에 걸림
    return quick_select(greater, k - len(less) - len(equal))

data = [7, 2, 5, 3, 9, 1]
print([quick_select(data, i) for i in range(len(data))])   # [1, 2, 3, 5, 7, 9]
```

> **함정**: 파이썬은 **재귀 깊이 기본 한계가 1000**이다. 재귀 정렬을 직접 구현할 땐 `sys.setrecursionlimit(10**6)`이 필요할 수 있다. 실전에서는 **직접 구현 대신 내장 `sort`를 쓰는 게 정답**이다.

## 7. 계수 정렬과 기수 정렬 ★★

비교 기반 정렬의 하한은 **O(n log n)** 이다. 하지만 **값의 범위가 작다면** 비교를 하지 않고 **O(n)** 에 정렬할 수 있다.

**계수 정렬(counting sort)**: 값을 인덱스로 삼아 개수만 센 뒤 순서대로 펼친다. **값 범위 k에 대해 O(n + k)** 시간·메모리.

```python
def counting_sort(arr, max_val):
    cnt = [0] * (max_val + 1)
    for x in arr:
        cnt[x] += 1                     # 값 자체를 인덱스로
    res = []
    for v, c in enumerate(cnt):
        res.extend([v] * c)             # 개수만큼 펼치기
    return res

print(counting_sort([3, 1, 4, 1, 5, 9, 2, 6], 9))
# [1, 1, 2, 3, 4, 5, 6, 9]
```

> **함정**: 값이 10억까지 갈 수 있으면 `[0] * (10**9)`는 **메모리 초과**다. 계수 정렬은 **값 범위가 대략 10⁶~10⁷ 이하일 때만** 쓴다. 음수가 있으면 최솟값만큼 **오프셋을 더해** 인덱스를 맞춘다.

**기수 정렬(radix sort)**: 자릿수별로 계수 정렬을 반복한다. **낮은 자리부터(LSD)** 처리하며, 각 단계가 **안정 정렬이어야** 전체가 올바르게 된다. d자리 수에 대해 O(d(n + k)).

```python
def radix_sort(arr):
    if not arr:
        return []
    res = arr[:]
    exp = 1
    max_val = max(res)
    while max_val // exp > 0:
        buckets = [[] for _ in range(10)]
        for x in res:
            buckets[(x // exp) % 10].append(x)   # 현재 자릿수로 분배
        res = [x for b in buckets for x in b]    # 순서대로 다시 모음(안정)
        exp *= 10
    return res

print(radix_sort([170, 45, 75, 90, 802, 24, 2, 66]))
# [2, 24, 45, 66, 75, 90, 170, 802]
```

## 8. 정렬 알고리즘 비교표 ★★

| 알고리즘 | 최선 | 평균 | 최악 | 추가 공간 | 안정성 | 비고 |
|---|---|---|---|---|---|---|
| 버블 | O(n) | O(n²) | O(n²) | O(1) | 안정 | 교육용 |
| 선택 | O(n²) | O(n²) | O(n²) | O(1) | 불안정 | 교환 횟수 최소 |
| 삽입 | O(n) | O(n²) | O(n²) | O(1) | 안정 | 거의 정렬된 데이터에 강함 |
| 병합 | O(n log n) | O(n log n) | O(n log n) | O(n) | 안정 | 최악에도 보장 |
| 퀵 | O(n log n) | O(n log n) | **O(n²)** | O(log n) | 불안정 | 상수가 작아 빠름 |
| 힙 | O(n log n) | O(n log n) | O(n log n) | O(1) | 불안정 | 제자리 + 최악 보장 |
| 계수 | O(n + k) | O(n + k) | O(n + k) | O(k) | 안정 | 값 범위 작을 때만 |
| 기수 | O(d(n + k)) | O(d(n + k)) | O(d(n + k)) | O(n + k) | 안정 | 정수·문자열 |
| **Timsort** | **O(n)** | **O(n log n)** | **O(n log n)** | O(n) | **안정** | **파이썬 내장** |

> ★★★ **핵심**: 코딩테스트에서 정렬을 직접 구현할 이유는 거의 없다. **`sorted`가 Timsort로 이미 최적**이며, 직접 구현한 파이썬 코드는 C로 구현된 내장 정렬보다 수십 배 느리다. 구현 지식은 **개념·면접용**, 실전은 **내장 함수 + `key` 설계**다.

## 9. 좌표 압축 (Coordinate Compression) ★★★

**값의 범위는 크지만 실제 등장하는 값은 적을 때**, 값을 **0부터 시작하는 순위로 바꿔치기**하는 기법이다. **정렬 → 중복 제거 → 인덱스 매핑** 세 단계이며, 정렬의 가장 실전적인 응용이다.

```python
def compress(arr):
    uniq = sorted(set(arr))                       # 1) 정렬 + 중복 제거
    table = {v: i for i, v in enumerate(uniq)}    # 2) 값 -> 순위 dict
    return [table[v] for v in arr], uniq          # 3) 매핑

arr = [1000000000, -100, 7, 7, -100, 0]
comp, uniq = compress(arr)
print(comp)    # [3, 0, 2, 2, 0, 1]
print(uniq)    # [-100, 0, 7, 1000000000]
```

`dict` 대신 **`bisect_left`로 순위를 구할 수도 있다.** 메모리를 아끼는 대신 조회가 O(log n)이 된다.

```python
from bisect import bisect_left

arr = [1000000000, -100, 7, 7, -100, 0]
uniq = sorted(set(arr))
comp = [bisect_left(uniq, v) for v in arr]    # 값의 순위 = 정렬 배열에서의 위치
print(comp)    # [3, 0, 2, 2, 0, 1]
```

> ★★★ **핵심**: **대소 관계만 중요하고 값 자체는 중요하지 않을 때** 좌표 압축을 떠올린다. 값 범위가 10억인 세그먼트 트리·누적 카운팅·스위핑 문제를 등장 값 개수 규모로 줄여준다.

### 한 줄 요약
파이썬의 `sort`/`sorted`는 **Timsort**로 평균·최악 O(n log n)이며 **안정 정렬**이라, 덜 중요한 기준부터 여러 번 정렬하거나 `key`가 튜플을 반환하게 해서 **다중 기준 정렬**을 만들 수 있다. 버블·선택·삽입은 O(n²)로 개념·면접용이고, 병합 정렬은 최악에도 O(n log n)을 보장하며 역순 쌍 세기로 응용되고, 퀵 정렬은 평균은 빠르지만 피벗을 잘못 고르면 최악 O(n²)가 된다. 값 범위가 작을 때만 계수·기수 정렬로 O(n)이 가능하며, 범위가 크면 오히려 메모리 초과가 난다. 실전에서는 직접 구현 대신 **내장 정렬 + 잘 설계한 `key`**를 쓰고, 값 범위가 큰 문제는 **좌표 압축**으로 인덱스를 줄이는 것이 핵심이다.

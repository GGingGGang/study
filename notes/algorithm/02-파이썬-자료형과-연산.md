## 1. 정수 `int` — 오버플로가 없다 ★★★

파이썬의 `int`는 **임의 정밀도(arbitrary precision)** 다. 메모리가 허락하는 한 자릿수 제한이 없다. C++에서 `long long`을 넘겨 틀리는 사고가 파이썬에는 존재하지 않는다.

```python
import sys

print(2 ** 100)                     # 1267650600228229401496703205376
print(len(str(2 ** 1000)))          # 302  (302자리 정수도 그냥 다뤄진다)

a = 10 ** 18
print(a * a)                        # 1000000000000000000000000000000000000  (오버플로 없음)

print(sys.getsizeof(1))             # 28   작은 정수도 객체라 28바이트
print(sys.getsizeof(10 ** 100))     # 72   자릿수가 늘면 메모리도 늘어난다
```

| 특성 | 의미 | 코테에서의 함의 |
|---|---|---|
| 오버플로 없음 | 자릿수 무제한 | 큰 수 곱셈·팩토리얼·거듭제곱을 그냥 계산 |
| 객체 기반 | 정수 하나가 28바이트 이상 | **100만 개 리스트가 약 35MB** → 메모리 제한 주의 |
| 자릿수 비례 비용 | 자릿수가 커지면 연산이 느려짐 | 모듈러 연산으로 **수를 계속 작게 유지**하는 게 유리 |

> ★★★ **핵심**: 정답이 커지는 문제에서 "10007로 나눈 나머지를 출력하라" 같은 조건이 붙는 이유는 다른 언어의 오버플로 때문이지만, **파이썬에서도 모듈러를 매 단계 적용해야 빠르다.** 최종에 한 번만 `% MOD`를 하면 중간 값이 수천 자리로 불어나 느려진다.

```python
MOD = 1_000_000_007

bad = 1
for i in range(1, 501):             # 500! 은 1135자리짜리 거대 정수가 된다
    bad *= i
print(len(str(bad)), bad % MOD)     # 1135 688653593

good = 1
for i in range(1, 501):
    good = good * i % MOD           # 매 단계 나머지를 취해 값을 작게 유지
print(good)                         # 688653593  (결과는 동일, 훨씬 빠름)
```

파이썬은 **거듭제곱 모듈러도 내장**한다. 직접 분할정복을 짤 필요가 없다.

```python
MOD = 1_000_000_007
print(pow(2, 1000, MOD))            # 688423210   (2^1000 mod MOD, 빠른 거듭제곱)
print(pow(3, MOD - 2, MOD))         # 333333336   (모듈러 곱셈 역원, 페르마 소정리)
print(pow(3, -1, MOD))              # 333333336   (파이썬 3.8+ 음수 지수 = 역원)
```

## 2. 실수 `float`의 오차 ★★★

`float`는 **이진 부동소수점**이라 `0.1` 같은 십진 소수를 정확히 표현하지 못한다. **실수는 `==`로 비교하지 않는다.**

```python
import math

print(0.1 + 0.2)                    # 0.30000000000000004
print(0.1 + 0.2 == 0.3)             # False  ← 절대 이렇게 비교하지 말 것
print(f'{0.1 + 0.2:.17f}')          # 0.30000000000000004

print(math.isclose(0.1 + 0.2, 0.3))                     # True
print(abs((0.1 + 0.2) - 0.3) < 1e-9)                    # True  (직접 오차 허용)

print(int(2.9999999999999996))      # 2   ← 내림이라 한 칸 어긋난다
print(round(2.9999999999999996))    # 3
```

| 상황 | 위험한 코드 | 안전한 코드 |
|---|---|---|
| 같은지 비교 | `a == b` | `abs(a - b) < 1e-9` 또는 `math.isclose(a, b)` |
| 제곱근이 정수인지 | `int(x ** 0.5) ** 2 == x` | **`math.isqrt(x) ** 2 == x`** |
| 나눗셈 후 정수화 | `int(a / b)` | **`a // b`** (음수에서 특히 다름) |
| 평균 비교 | `s1 / n1 > s2 / n2` | **`s1 * n2 > s2 * n1`** (정수 교차 곱) |

```python
import math

x = 10 ** 18 - 1                    # 정답은 999999999 (999999999^2 <= x < 10^18)
print(int(x ** 0.5))                # 1000000000 ← float 변환 중 반올림되어 1 초과
print(math.isqrt(x))                # 999999999  ← 정확한 정수 제곱근
print(math.isqrt(x) ** 2 <= x)      # True

print(int(-7 / 2))                  # -3  (0 방향 절삭)
print(-7 // 2)                      # -4  (음의 무한대 방향 내림)
```

> ★★★ **핵심**: **가능하면 실수를 아예 쓰지 않는다.** 나눗셈 비교는 **교차 곱셈**으로, 제곱근은 **`math.isqrt`** 로, 거리 비교는 **제곱한 값 그대로** 비교하면 오차가 사라진다.

## 3. 나눗셈 세 가지 — `/`, `//`, `divmod` ★★★

| 연산 | 결과 타입 | 의미 |
|---|---|---|
| `a / b` | **항상 `float`** | 참 나눗셈. 큰 정수에서 **오차 발생** |
| `a // b` | 둘 다 정수면 `int` | **바닥 나눗셈**(floor, 음의 무한대 방향) |
| `a % b` | 정수 | 나머지. **부호는 `b`를 따른다** |
| `divmod(a, b)` | `(몫, 나머지)` 튜플 | `//`와 `%`를 **한 번에** (진법 변환에 유용) |

```python
print(7 / 2, 7 // 2, 7 % 2)         # 3.5 3 1
print(divmod(7, 2))                 # (3, 1)
print(divmod(255, 16))              # (15, 15)

print(10 ** 18 // 3)                # 333333333333333333  (정확)
print(int(10 ** 18 / 3))            # 333333333333333312  (오차! float 경유)
```

### 3.1 음수 나눗셈·나머지 — 파이썬 특유의 동작 ★★★

C, C++, Java는 몫을 **0 방향으로 절삭**하고 나머지는 **피제수(왼쪽) 부호**를 따른다. 파이썬은 몫을 **음의 무한대 방향으로 내림**하고, 나머지는 **제수(오른쪽) 부호**를 따른다.

```python
print(-7 // 2, -7 % 2)              # -4 1     (C/C++/Java 라면 -3, -1)
print(7 // -2, 7 % -2)              # -4 -1
print(-7 // -2, -7 % -2)            # 3 -1
print(divmod(-7, 2))                # (-4, 1)

print((-7) % 3)                     # 2   ← 나머지가 항상 0 이상 (b>0일 때)
print((-1) % 26)                    # 25  ← 원형 배열 인덱스에 그대로 쓸 수 있다
```

| 식 | 파이썬 | C/C++/Java |
|---|---|---|
| `-7 // 2` | **-4** | -3 |
| `-7 % 2` | **1** | -1 |
| `7 // -2` | **-4** | -3 |
| `7 % -2` | **-1** | 1 |

**항등식 `a == (a // b) * b + a % b` 는 파이썬에서도 항상 성립한다.**

```python
for a in (-7, 7, -8, 8):
    for b in (3, -3):
        assert a == (a // b) * b + a % b
print('항등식 성립 확인')            # 항등식 성립 확인
```

> ★★★ **핵심**: 양수 `m`에 대해 **`x % m`은 항상 `0 <= 결과 < m`** 이다. 이 성질 덕분에 **원형 배열의 인덱스 이동**(`(i - 1) % n`)이나 **음수를 포함한 모듈러 연산**에서 별도 보정이 필요 없다. 반대로 "0 방향 절삭"이 필요하면 `int(a / b)`가 아니라 `-(-a // b)` 또는 `math.trunc` 계열을 쓴다.

```python
import math

a, b = -7, 2
print(-(-a // b))                   # -3  (0 방향 절삭을 정수 연산으로 구현)
print(math.trunc(-3.7), math.floor(-3.7), math.ceil(-3.7))   # -3 -4 -3
print(-(-7 // 2))                   # 4   ← 올림 나눗셈 관용구: ceil(7/2)
print(-(-10 // 3))                  # 4   ← ceil(10/3)
```

## 4. 비트 연산 ★★★

집합을 정수 하나로 표현하는 **비트마스크**, 2의 거듭제곱 처리, 부분집합 순회에 필수다.

| 연산자 | 이름 | 예시 | 결과 |
|---|---|---|---|
| `a << k` | 왼쪽 시프트 | `1 << 5` | `32` (= `2**5`) |
| `a >> k` | 오른쪽 시프트 | `40 >> 3` | `5` (= `40 // 8`) |
| `a & b` | AND | `12 & 10` | `8` |
| `a \| b` | OR | `12 \| 10` | `14` |
| `a ^ b` | XOR | `12 ^ 10` | `6` |
| `~a` | NOT (보수) | `~5` | `-6` (= `-(5+1)`) |

```python
print(1 << 5, 40 >> 3)              # 32 5
print(12 & 10, 12 | 10, 12 ^ 10)    # 8 14 6
print(~5, ~0, ~(-1))                # -6 -1 0

x = 0b1011                          # 11
print(x & 1)                        # 1   마지막 비트 = 홀수 판정
print(x & -x)                       # 1   가장 낮은 켜진 비트 (lowbit)
print(x.bit_length())               # 4   유효 비트 수
print(x.bit_count())                # 3   켜진 비트 개수 (파이썬 3.10+)
print(bin(x).count('1'))            # 3   3.10 미만에서 쓰던 방식
```

### 4.1 비트마스크 관용구

```python
mask = 0
mask |= (1 << 3)                    # 3번 원소 추가
mask |= (1 << 5)                    # 5번 원소 추가
print(bin(mask))                    # 0b101000

print(mask & (1 << 3) != 0)         # True   3번이 포함되어 있는가
print((mask >> 5) & 1)              # 1      5번 비트만 뽑기
mask &= ~(1 << 3)                   # 3번 원소 제거
print(bin(mask))                    # 0b100000
mask ^= (1 << 5)                    # 5번 토글 (있으면 빼고 없으면 넣기)
print(mask)                         # 0

n = 3
print((1 << n) - 1)                 # 7 = 0b111   n개 원소 전체 집합
subsets = [[i for i in range(n) if s >> i & 1] for s in range(1 << n)]
print(subsets)                      # 모든 부분집합 (2^n 개)
# [[], [0], [1], [0, 1], [2], [0, 2], [1, 2], [0, 1, 2]]
```

> **함정**: 파이썬 정수는 **무한 비트**이므로 `~x`는 상위 비트가 계속 1인 음수가 된다. "n비트 안에서의 보수"를 원하면 `~x & ((1 << n) - 1)` 처럼 **마스크로 잘라야** 한다.

```python
n = 4
x = 0b0101
print(~x)                           # -6           의도와 다름
print(~x & ((1 << n) - 1))          # 10 (0b1010)  n비트 보수
print(bin(~x & ((1 << n) - 1)))     # 0b1010
```

## 5. 진법 변환 ★★

```python
n = 255
print(bin(n), oct(n), hex(n))       # 0b11111111 0o377 0xff
print(bin(n)[2:], f'{n:b}', f'{n:x}', f'{n:X}')     # 11111111 11111111 ff FF
print(f'{5:08b}')                   # 00000101   자릿수 채우기
print(int('11111111', 2), int('ff', 16), int('377', 8))     # 255 255 255
print(int('zz', 36))                # 1295   int(문자열, 진법)은 2~36진법 지원
```

임의 진법(예: 7진법)으로 바꾸려면 `divmod`를 반복한다.

```python
def to_base(n, base):
    """n을 base 진법 문자열로 변환 (0 <= n)"""
    digits = '0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ'
    if n == 0:
        return '0'                  # 0은 루프가 안 돌아 별도 처리 필요
    out = []
    while n:
        n, r = divmod(n, base)      # 몫과 나머지를 한 번에
        out.append(digits[r])
    return ''.join(reversed(out))   # 나머지는 거꾸로 나오므로 뒤집는다

print(to_base(255, 7))              # 513
print(to_base(0, 7))                # 0
print(int(to_base(255, 7), 7))      # 255  (역변환으로 검증)
```

> **함정**: `to_base`에서 **`n == 0` 처리를 빼먹는 실수**가 매우 흔하다. `while n` 루프가 한 번도 안 돌아 빈 문자열이 나온다.

## 6. 무한대와 극한값 ★★

DP 초기화, 최단경로 초기화, 최솟값·최댓값 갱신에 쓴다.

```python
import math

INF = float('inf')
print(INF, math.inf, INF == math.inf)       # inf inf True
print(INF > 10 ** 100, -INF < -10 ** 30)    # True True
print(min(INF, 5), max(-INF, 5), INF + 1)   # 5 5 inf
INT_INF = 10 ** 18                          # int(float('inf')) 는 OverflowError!
print(INT_INF > 10 ** 17, type(INT_INF))    # True <class 'int'>

nan = float('nan')
print(nan == nan, math.isnan(nan))          # False True  ← NaN은 자기 자신과도 다르다
```

| 용도 | 권장 값 | 이유 |
|---|---|---|
| 최솟값 갱신 초기값 | `float('inf')` 또는 큰 정수 `10**18` | 어떤 값보다도 큼 |
| 최댓값 갱신 초기값 | `float('-inf')` 또는 `-10**18` | 어떤 값보다도 작음 |
| **정수만 다루는 DP** | **`10**18` 같은 큰 정수 권장** | `int`로 유지되어 **`//`·`%`가 정상 동작**하고 출력도 깔끔 |

> **함정**: `float('inf')`가 섞이면 배열 전체가 `float`로 물들어 **큰 정수 정밀도가 깨지고**, 결과를 그대로 출력하면 `inf`나 `3.0` 같은 표기가 나온다. **정수 문제에서는 `INF = 10**18`처럼 정수 상수를 쓰는 편이 안전하다.**

## 7. 문자와 아스키 코드 ★★

```python
print(ord('A'), ord('a'), ord('0'))         # 65 97 48
print(chr(65), chr(97), chr(48))            # A a 0
print(ord('C') - ord('A'), chr(ord('A') + 2))   # 2 C   인덱스 ↔ 문자
print(ord('가'), chr(44032))                # 44032 가   유니코드도 동일하게 동작

cnt = [0] * 26
for ch in 'abcXYZ'.lower():
    cnt[ord(ch) - ord('a')] += 1            # 알파벳 카운팅 배열의 정석
print(cnt[:3], cnt[23:])                    # [1, 1, 1] [1, 1, 1]

msg = 'HELLO'                               # 시저 암호: 3칸 밀기 (대문자)
print(''.join(chr((ord(c) - ord('A') + 3) % 26 + ord('A')) for c in msg))   # KHOOR
```

| 문자 | 코드값 | 활용 |
|---|---|---|
| `'0'` ~ `'9'` | 48 ~ 57 | `ord(c) - 48` = 숫자값 (`int(c)`도 가능) |
| `'A'` ~ `'Z'` | 65 ~ 90 | `ord(c) - 65` = 0~25 인덱스 |
| `'a'` ~ `'z'` | 97 ~ 122 | 대소문자 차이는 정확히 **32** |

```python
print(ord('a') - ord('A'))                  # 32   대소문자 차이는 정확히 32
print(chr(ord('A') | 32), chr(ord('a') & ~32))      # a A   비트로 대소문자 변환
print('7'.isdigit(), 'a'.isalpha(), 'a'.isupper())  # True True False
```

## 8. 코테에서 자주 쓰는 수치 관용구 ★★

```python
import math

print(math.gcd(12, 18), math.gcd(12, 18, 24))       # 6 6   (3.9+ 다중 인자)
print(math.lcm(4, 6), 4 * 6 // math.gcd(4, 6))      # 12 12
print(math.isqrt(999), math.isqrt(1000))            # 31 31
print(math.comb(10, 3), math.perm(10, 3), math.factorial(10))    # 120 720 3628800
print(abs(-5), max(3, 9), min(3, 9), sum([1, 2, 3]), divmod(17, 5))  # 5 9 3 6 (3, 2)
print(round(2.5), round(3.5), round(2.675, 2))      # 2 4 2.67  ← 은행가 반올림 주의
print(10 ** 9 + 7)                                  # 1000000007  자주 쓰는 소수 MOD
```

> **함정**: 파이썬 `round()`는 **은행가 반올림(banker's rounding)** 이라 `.5`에서 짝수 쪽으로 간다(`round(2.5) == 2`). 문제가 "0.5는 올림"을 요구하면 **`math.floor(x + 0.5)`** 나 정수 연산 `(a * 2 + b) // (b * 2)` 형태로 직접 구현한다.

### 한 줄 요약
파이썬의 `int`는 **오버플로가 없는 대신 객체라 메모리를 먹고 자릿수가 커지면 느려지므로**, 큰 수는 매 단계 `% MOD`로 작게 유지하고 거듭제곱은 `pow(a, b, m)`을 쓴다. **실수는 `==`로 비교하지 말고** `math.isclose`나 오차 허용치를 쓰되, 근본적으로는 **교차 곱셈·`math.isqrt`·제곱 비교로 정수 연산으로 우회**하는 것이 최선이다. `//`와 `%`는 **음의 무한대 방향 내림**이라 `-7 // 2 == -4`, `-7 % 2 == 1`이고, 이 덕분에 **원형 인덱스 `(i-1) % n`이 보정 없이 동작**한다. 비트 연산은 **집합을 정수 하나로 표현하는 비트마스크**의 기반이며, 파이썬 정수는 비트 수가 무한하므로 **`~x`는 반드시 `& ((1<<n)-1)`로 잘라서** 써야 한다.

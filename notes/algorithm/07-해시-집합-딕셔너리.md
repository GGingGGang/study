> 알고리즘 · 자료구조 · 학습내용: 해시 기반 평균 O(1) 조회 원리, `list`의 `in`(O(n))과 `set`의 `in`(O(1)) 차이, `defaultdict`·`setdefault`·`Counter`, 집합 연산(합·교·차·대칭차), dict 순회와 정렬, 삽입 순서 보존(3.7+), 좌표 압축의 도구로서의 dict, 튜플을 키로 쓰기와 unhashable 함정, 해시 충돌과 최악 O(n)

## 1. 해시 테이블의 원리 ★★★

`dict`와 `set`은 **해시 테이블(hash table)** 이다. 키를 `hash()` 함수로 정수로 바꾸고, 그 값을 테이블 크기로 나눈 나머지 위치에 바로 저장한다. **키 하나를 찾는 데 처음부터 훑을 필요가 없으므로 평균 O(1)** 이다.

```python
print(hash(42), hash("abc") == hash("abc"))   # 같은 값은 항상 같은 해시
print(hash((1, 2)))                           # 튜플도 해시 가능

# 리스트는 변경 가능(mutable)해서 해시할 수 없다
try:
    hash([1, 2])
except TypeError as e:
    print("TypeError:", e)
```

| 연산 | list | set / dict |
|---|---|---|
| `x in 자료구조` | **O(n)** | **평균 O(1)** |
| 원소 추가 | `append` O(1) | `add`/`d[k]=v` 평균 O(1) |
| 원소 삭제 | `remove` O(n) | `discard`/`del` 평균 O(1) |
| 순서 | 유지 | dict은 삽입 순서 유지, set은 순서 없음 |
| 중복 | 허용 | 불허 |

> ★★★ **핵심**: **"이미 나왔나?"를 반복해서 물어보는 코드에서 `list`의 `in`을 쓰면 O(n²)** 가 된다. 방문 체크·중복 제거·존재 확인은 무조건 `set`이다.

```python
import time

N = 30000
data = list(range(N))
lst, st = [], set()

t0 = time.perf_counter()
for x in data:
    if x not in lst:          # O(n) 검사 -> 전체 O(n^2)
        lst.append(x)
t1 = time.perf_counter()

for x in data:
    if x not in st:           # 평균 O(1) -> 전체 O(n)
        st.add(x)
t2 = time.perf_counter()

print(f"list in : {t1 - t0:.4f}s")
print(f"set  in : {t2 - t1:.4f}s")
print("set이 더 빠른가?", (t2 - t1) < (t1 - t0))
```

## 2. 해시 충돌과 최악 O(n) ★

서로 다른 키가 같은 해시 위치로 가는 것을 **충돌(collision)** 이라 한다. CPython은 **오픈 어드레싱(open addressing)** 으로 빈 자리를 탐색해 해결한다. 충돌이 잦으면 탐색이 길어져 **최악의 경우 O(n)** 까지 나빠진다.

실전에서 조심할 부분은 하나다. **정수 키를 쓸 때 값이 규칙적으로 배치되면 성능이 나빠질 수 있다.** 파이썬 정수의 해시는 값 그 자체라(작은 정수 기준) 특정 패턴에서 충돌이 몰릴 수 있다. 그럴 땐 **키를 문자열로 바꾸거나 임의 값을 섞는(예: `x * 임의소수 ^ 상수`) 방식**으로 회피한다. 다만 대부분의 문제에서는 신경 쓸 필요가 없다.

> **함정**: `set`은 **정렬돼 있지 않다.** 출력 순서가 필요한 문제에서 `print(*s)`를 하면 채점 결과가 흔들린다. **`sorted(s)`로 명시 정렬**해서 출력한다.

## 3. dict 기본과 삽입 순서 보존 ★★

**파이썬 3.7부터 `dict`는 삽입 순서를 보존한다**(3.6에서는 구현 세부사항, 3.7에서 언어 명세로 확정). 그래서 `collections.OrderedDict`가 필요한 경우는 거의 없다.

```python
d = {}
d["c"] = 3
d["a"] = 1
d["b"] = 2
print(list(d))            # ['c', 'a', 'b'] <- 넣은 순서 그대로

# 안전한 조회
print(d.get("z"))         # None (KeyError 안 남)
print(d.get("z", 0))      # 0 (기본값)

# 순회
for k, v in d.items():
    print(k, v)

print(list(d.keys()), list(d.values()))

# 삭제
del d["c"]
print(d.pop("a", -1), d.pop("없음", -1))   # 1 -1
```

| 목적 | 코드 |
|---|---|
| 키 존재 확인 | `k in d` (평균 O(1)) |
| 기본값 조회 | `d.get(k, default)` |
| 없을 때만 넣고 값 반환 | `d.setdefault(k, default)` |
| 삭제(없어도 안전) | `d.pop(k, default)` |
| 병합 | `d1 \| d2` (3.9+), `d1.update(d2)` |

## 4. defaultdict 와 setdefault ★★★

카운팅이나 그룹핑에서 **"키가 없으면 초기화" 코드를 매번 쓰는 것을 없애준다.**

```python
from collections import defaultdict

# int: 카운팅 (없는 키는 0으로 시작)
cnt = defaultdict(int)
for ch in "banana":
    cnt[ch] += 1
print(dict(cnt))          # {'b': 1, 'a': 3, 'n': 2}

# list: 그룹핑 / 인접 리스트
graph = defaultdict(list)
for u, v in [(1, 2), (1, 3), (2, 3)]:
    graph[u].append(v)
    graph[v].append(u)
print(dict(graph))

# set: 중복 없는 그룹핑
tags = defaultdict(set)
tags["py"].add("코테")
tags["py"].add("코테")
print(dict(tags))         # {'py': {'코테'}}
```

`setdefault`는 **일반 dict에서 같은 일을 한다.** "없으면 이 값을 넣고, 어쨌든 최종 값을 돌려준다."

```python
d = {}
d.setdefault("a", []).append(1)
d.setdefault("a", []).append(2)   # 이미 있으므로 기존 리스트에 붙는다
print(d)                          # {'a': [1, 2]}
```

> **함정**: `defaultdict`는 **읽기만 해도 키가 생긴다.** `if graph[99]:` 라고 조회하는 순간 키 `99`가 빈 리스트로 만들어져 `len(graph)`가 늘어난다. 존재 확인은 반드시 **`if 99 in graph:`** 로 한다.

```python
from collections import defaultdict

g = defaultdict(list)
print(len(g))          # 0
_ = g[99]              # 단순 조회인데 키가 생성됨
print(len(g), dict(g)) # 1 {99: []}
```

## 5. Counter ★★★

**개수 세기 전용 dict**이다. 문자열·리스트를 그대로 넣으면 원소별 개수를 만들어 준다.

```python
from collections import Counter

c = Counter("aabbbcc")
print(c)                       # Counter({'b': 3, 'a': 2, 'c': 2})
print(c["b"], c["z"])          # 3 0  (없는 키는 0, KeyError 안 남)

print(c.most_common(2))        # [('b', 3), ('a', 2)] 많은 순 정렬
print(sum(c.values()))         # 7  전체 개수
print(sorted(c.elements()))    # 원소를 개수만큼 펼치기

# 산술 연산
a, b = Counter("aabbc"), Counter("abd")
print(a + b)                   # 개수 합
print(a - b)                   # 뺄셈: 0 이하는 사라진다
print(a & b)                   # 교집합: 각 키의 min
print(a | b)                   # 합집합: 각 키의 max
```

**애너그램 판정, 문자 구성 비교**는 `Counter` 비교 한 줄이면 끝난다.

```python
from collections import Counter

def is_anagram(s, t):
    return Counter(s) == Counter(t)

print(is_anagram("listen", "silent"), is_anagram("abc", "abd"))   # True False
```

**"a로 b를 만들 수 있는가"** 같은 포함 판정은 뺄셈으로 본다.

```python
from collections import Counter

def can_make(source, target):
    # target에서 source를 뺐을 때 남는 게 없으면 만들 수 있다
    return not (Counter(target) - Counter(source))

print(can_make("aabbc", "abc"))   # True
print(can_make("abc", "aab"))     # False (a가 하나 모자람)
```

> **함정**: `most_common()`은 **개수가 같으면 처음 등장한 순서**를 따른다. "개수가 같으면 사전순" 같은 조건이 붙으면 **`sorted(c.items(), key=lambda x: (-x[1], x[0]))`** 로 직접 정렬해야 한다.

```python
from collections import Counter

c = Counter("bbaacc")
print(sorted(c.items(), key=lambda x: (-x[1], x[0])))
# [('a', 2), ('b', 2), ('c', 2)]  개수 내림차순, 같으면 사전순
```

## 6. 집합 연산 (Set Operations) ★★

| 연산 | 기호 | 메서드 | 의미 |
|---|---|---|---|
| 합집합 | `a \| b` | `a.union(b)` | 둘 중 하나라도 |
| 교집합 | `a & b` | `a.intersection(b)` | 둘 다 |
| 차집합 | `a - b` | `a.difference(b)` | a에만 |
| 대칭차 | `a ^ b` | `a.symmetric_difference(b)` | 한쪽에만 |
| 부분집합 | `a <= b` | `a.issubset(b)` | a가 b에 포함 |
| 서로소 | — | `a.isdisjoint(b)` | 교집합이 비었나 |

```python
a = {1, 2, 3, 4}
b = {3, 4, 5}

print(sorted(a | b))        # [1, 2, 3, 4, 5]
print(sorted(a & b))        # [3, 4]
print(sorted(a - b))        # [1, 2]
print(sorted(a ^ b))        # [1, 2, 5]
print({1, 2} <= a, a.isdisjoint({9}))   # True True

# 중복 제거 + 정렬 (좌표 압축의 재료)
raw = [5, 3, 5, 1, 3]
print(sorted(set(raw)))     # [1, 3, 5]
```

> **함정**: 빈 집합은 `{}`가 아니라 **`set()`** 이다. `{}`는 빈 **dict**다. 그리고 집합 연산은 **`set`끼리만** 되므로, `a | [1,2]`는 `TypeError`다. 리스트와 섞으려면 `a | set([1,2])`.

```python
print(type({}), type(set()))     # <class 'dict'> <class 'set'>
```

## 7. dict 정렬과 순회 ★★

dict 자체는 정렬 상태를 유지하지 않는다. **필요할 때 `sorted`로 뽑아낸다.**

```python
score = {"kim": 90, "lee": 75, "park": 90, "choi": 60}

print(sorted(score))                                   # 키 오름차순 (키만)
print(sorted(score.items()))                           # (키, 값) 튜플 정렬
print(sorted(score.items(), key=lambda x: x[1]))       # 값 오름차순
print(sorted(score.items(), key=lambda x: -x[1]))      # 값 내림차순
print(sorted(score.items(), key=lambda x: (-x[1], x[0])))  # 값 내림차순, 같으면 이름순

print(max(score, key=score.get))     # 값이 가장 큰 '키' -> 'kim'

# 정렬 결과를 다시 dict로 (삽입 순서가 유지되므로 정렬된 dict가 된다)
ordered = dict(sorted(score.items(), key=lambda x: -x[1]))
print(list(ordered))
```

## 8. 튜플을 키로 쓰기 ★★

**해시 가능한(hashable) 값만 키가 될 수 있다.** 불변(immutable)이면 대체로 해시 가능하다.

| 키로 가능 | 키로 불가능 |
|---|---|
| `int`, `str`, `float`, `bool` | `list` |
| `tuple`(원소가 전부 해시 가능할 때) | `dict` |
| `frozenset` | `set` |

```python
# 2차원 좌표를 키로 (희소 격자에 유용)
visited = set()
visited.add((3, 5))
print((3, 5) in visited, (5, 3) in visited)   # True False

board = {}
board[(0, 0)] = "X"
board[(1, 2)] = "O"
print(board)

# 리스트를 키로 쓰면 에러 -> tuple로 변환
try:
    {}[[1, 2]] = 1
except TypeError as e:
    print("TypeError:", e)

d = {tuple([1, 2]): "ok"}
print(d[(1, 2)])

# 원소에 리스트가 들어간 튜플도 불가
try:
    hash((1, [2]))
except TypeError as e:
    print("TypeError:", e)

# 집합을 키로 쓰려면 frozenset
print({frozenset({1, 2}): "set key"})
```

> **함정**: 격자가 조밀하면 `dict[(r, c)]`보다 **2차원 리스트가 훨씬 빠르다.** 해시 계산 비용이 있기 때문이다. **좌표 범위가 매우 크고 실제 사용 칸이 적을 때(희소)** 튜플 키를 쓴다.

## 9. 좌표 압축의 도구로서 dict ★★★

값의 범위가 10억인데 **실제 등장하는 값은 몇 만 개뿐**일 때, 값을 **0부터 시작하는 작은 인덱스로 바꿔치기**하는 기법이 **좌표 압축(coordinate compression)** 이다. 배열 크기를 등장한 값의 개수만큼으로 줄일 수 있다.

**정렬 + 중복 제거 + dict 매핑** 세 단계다.

```python
def compress(arr):
    # 1) 중복 제거 후 정렬 -> 2) 값 -> 순위 dict
    table = {v: i for i, v in enumerate(sorted(set(arr)))}
    return [table[v] for v in arr], table

arr = [1000000000, -5, 7, 7, -5]
comp, table = compress(arr)
print(comp)      # [2, 0, 1, 1, 0]
print(table)     # {-5: 0, 7: 1, 1000000000: 2}
```

압축된 값으로 카운팅 배열을 만들면 메모리가 산다.

```python
arr = [10**9, -5, 7, 7, -5, 10**9]
table = {v: i for i, v in enumerate(sorted(set(arr)))}

cnt = [0] * len(table)          # 3칸이면 충분
for v in arr:
    cnt[table[v]] += 1
print(cnt)                      # [2, 2, 2]

# 역변환(순위 -> 원래 값)
inv = {i: v for v, i in table.items()}
print([inv[i] for i in range(len(inv))])   # [-5, 7, 1000000000]
```

> ★★★ **핵심**: 좌표 압축은 **"값 자체는 중요하지 않고 대소 관계만 중요할 때"** 쓴다. 세그먼트 트리, 누적 카운팅, 스위핑 문제에서 값 범위가 클 때 거의 자동으로 따라 나온다.

### 한 줄 요약
`dict`와 `set`은 해시 테이블이라 **조회·삽입·삭제가 평균 O(1)** 이고, 존재 확인을 반복하는 코드에서 `list`의 `in`(O(n))을 쓰면 곧바로 O(n²)로 무너지므로 **방문 체크와 중복 제거는 항상 `set`**을 쓴다. 카운팅은 `defaultdict(int)`나 `Counter`로 정리되고, `Counter`의 뺄셈·교집합은 애너그램·포함 판정을 한 줄로 만들어 준다. `dict`는 **3.7+에서 삽입 순서를 보존**하지만 정렬은 하지 않으므로 `sorted(d.items(), key=...)`로 명시적으로 뽑아야 하고, `set`의 출력 순서도 믿으면 안 된다. 좌표를 키로 쓸 때는 리스트가 unhashable이라 **튜플로 바꿔야** 하며, 값 범위가 클 때는 `dict`로 **좌표 압축**해 배열 크기를 줄인다.

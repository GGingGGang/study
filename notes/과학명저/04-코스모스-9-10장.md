> 9장 별들의 삶과 죽음 · 10장 영원의 벼랑 끝

## 9장 별들의 삶과 죽음

### 핵심 주제
1. **코스모스의 후예**
2. **별의 일생 (탄생과 진화)**
3. **별 먼지(star dust)**

> 핵심 명제: 태어나고 살고 죽는 인간의 삶처럼 별도 탄생·진화·죽음을 거치며, **인간(생명체)은 물리적·화학적으로 우주와 연결되어 있다.**

### 1) 애플파이의 은유 — 원자의 기원

- "애플파이를 맨 처음부터 만들려면 **우주의 탄생에서부터 시작**해야 한다"
- 파이 → 분자 → 원자. 그렇다면 **원자는 어디서 왔는가?**
  - **수소를 제외한 나머지 원자는 모두 별의 내부에서 만들어졌다** → **별 = 우주의 부엌**
  - 별은 주로 수소로 된 성간 기체 + 소량의 성간 티끌이 뭉쳐 만들어짐
  - **수소는 대폭발(빅뱅)에서 만들어졌다** → 수소 원자는 코스모스가 비롯된 거대 폭발에서 태어남
- 결론: **우리는 가장 근본적 의미에서 코스모스의 자녀들이다** (생명체 구성 주요 4원소 = **CHON**)
- 전 우주 물질의 **75%가 수소** → 태초의 수소가 인간의 몸에도 있다

### 2) 물질·원자론의 역사

- 원자번호 = 원자의 정체성 = **원자핵 속 양성자 개수**
- 무거운 원소를 만드는 과정: 핵융합(별의 중심), 중성자 포획(초신성 폭발), 블랙홀·중성자별 충돌, 핵분열

#### 고대 그리스 원자론 — 데모크리토스(Democritus, ca. 460 BC)
- **atomos** = 부정의 a- + 나눔의 -tomos = "더 이상 나눌 수 없는 존재"
- 온 세계는 무한히 많은 작은 원자로 구성, 원자는 진공 중에서 끊임없이 움직임
- 창조된 것이 아니라 다양한 크기·모양으로 무한히 오래 존재. 모양·배열·위치에 따라 성질이 다름

#### 현대 원자론 — 돌턴(John Dalton, 1766~1844)
- 모든 물질은 유한한 수의 원자로 이루어짐. 작용하는 힘에 따라 기체·액체·고체 상태
- 여러 원자가 결합해 화합물 형성. 라부아지에·프루스트의 연구에 기반
- 원자모형의 변천: **톰슨(J.J. Thomson) → 러더퍼드(Rutherford) → 보어(Bohr) → 하이젠베르크(Heisenberg)** (채드윅=중성자 발견)
- 원자는 더 작은 단위로 **나누어진다** (양성자·중성자 → 쿼크의 종류·수 조합)

### 3) 별의 탄생

- 별이 태어나는 곳 = **성운(nebula, 성간운, interstellar cloud)**: 수소와 먼지(티끌)가 뭉쳐 있는 상태
- 과정: 성운 내 외부 충격으로 물질 분포가 불균일 → 밀한 곳에서 물질이 뭉침 → **중력 수축**으로 질량이 커져 **임계 질량(진스 질량, Jeans mass)**을 넘으면 가속 수축 → **원시별** 형성
- **원시별의 질량이 이후 진화 경로를 결정**
- 별 내부의 에너지(핵융합) ↔ 중력의 **균형(평형)** = 별. 평형이 깨지면 폭발

### 4) 질량에 따른 별의 진화·죽음

| 질량 | 진화·종말 |
|------|-----------|
| 작은 질량 (태양 정도) ~ 중간 질량 (태양의 4~8배) | **행성상 성운 → 백색 왜성** |
| 큰 질량 (태양의 8~10배 이상) | **초신성 → 중성자별 또는 블랙홀** |

- 별 내부에서 만들어진 원자들을 성간으로 방출, 초신성 폭발 과정에서 더 무거운 원자들을 성간으로 방출
- 별의 일생 단계(본문): 암흑 성간운 → (중력 수축) → 원시 행성계 → 초거성/주계열성 → 적색 거성 → 백색 왜성·행성상 성운 / 신성·초신성·중성자별·블랙홀

### 5) 핵융합과 핵분열

| 구분 | 핵융합(nuclear fusion) | 핵분열(nuclear fission) |
|------|----------------------|------------------------|
| 정의 | 가벼운 원자핵들이 고온에서 충돌해 무거운 원자핵 형성 | 무거운 원자핵이 중성자와 충돌해 둘 이상으로 분열 |
| 조건 | 2천만~1억 도 이상 초고온 **플라즈마** | ²³⁵U 등 무거운 핵, 방출 중성자로 연쇄반응 |
| 예 | **태양 에너지 생산**, 중수소·삼중수소 | 원자폭탄·원자로 |

- 핵융합 원리: 원자핵 사이엔 전자기력(+)이 밀어내나, 아주 가까운 거리에선 **강한 핵력**이 전자기력보다 강해짐 → 1000만 도 이상 가열(플라즈마) 필요
- 결합 시 **결손질량**이 에너지로 방출 (**E=mc²**). 무거운 원자 핵융합엔 더 높은 온도 필요
- 물질의 상태 변화: 고체 → 액체 → 기체 → **플라즈마**
- 태양: 초당 수소 6억 2천만 톤 사용

### 6) 별 먼지 & 코스모스의 후예

- **별 먼지**: 인간의 진화가 우주·별의 진화와 연관. 생명의 기원·진화 = 별의 기원·진화
- 생명과 우주의 연결(요약):
  1. 우리를 구성하는 물질은 오래전 은하 어딘가의 **적색 거성**에서 만들어진 것
  2. 지구의 무거운 원소 일부 동위원소는 태양 탄생 직전 근처 **초신성 폭발**을 시사
  3. 지구 생명 활동은 모두 **태양 에너지에 의존**
  4. 유전 형질의 변화(돌연변이)가 진화를 추동 — **고에너지 우주선(cosmic ray) 입자**가 돌연변이 촉발 가능
  5. 지구상 생명체 멸종 사건도 우주의 사건과 연결 (예: 소행성 충돌, 약 2,600만 년 전 80% 멸종·공룡 멸종)
- 결론: **우리는 코스모스와 깊이 연관되어 있고 그 일부이다.** 진화를 끌어가는 것 = 적응 + 우연(무작위) + 우주선 입자의 영향

## 10장 영원의 벼랑 끝

### 핵심 주제
1. **팽창 우주 — 대폭발이론(빅뱅), 현대천문학의 패러다임**
2. **우주의 운명** — 대폭발이론(천문학), 아인슈타인 우주상수, 우주기원론(수학)

### 1) 팽창 우주의 발견 — 도플러 효과

- 우주의 대폭발과 은하의 후퇴 운동을 발견한 핵심 원리 = **도플러 효과**
- **허블(Edwin Hubble, 1929)**: 도플러 효과(적색이동)를 통해 발견
  - **멀리 있는 은하일수록 더 빨리 후퇴한다**
  - 새 해석: 천체가 움직이는 게 아니라 **우주 공간 자체가 팽창**한다고 보면 설명 가능
- **허블의 법칙**: **v = H·r** (후퇴 속도 = 허블 상수 × 거리). 우주의 모든 곳이 팽창하므로 멀수록 팽창이 누적됨

### 2) 두 가지 우주론적 물음

- **우주기원론(cosmogony)**: 우주 생성에 대한 이론 ("어떻게 생겼나", 과거)
- **우주진화론**: 우주의 운명·미래 (수축/팽창/정지)
- 우주가 팽창한다 → 시간을 거꾸로 돌리면 물질이 한 점(**특이점, singularity**)으로 수렴, 과거로 갈수록 밀도·온도 증가

### 3) 빅뱅 vs 정상우주론 — 현대우주론의 전개

| 연도/인물 | 주장 |
|-----------|------|
| 1917 아인슈타인 | **정적 우주론**: 우주는 팽창도 수축도 안 함 (우주상수 도입) |
| 1922 프리드만 / 1927 르메트르 | 일반상대성이론상 **우주는 팽창해야 한다**. 르메트르: "우주는 원시원자들의 폭발로 시작" (아인슈타인은 이들 논문을 무시) |
| 1929 허블 | 은하 후퇴 발견 → 우주 팽창 → 아인슈타인이 우주상수를 후회 |
| 1946 가모브(Gamow) | 초기 우주를 처음 계산: **원시 불덩이(primeval fireball)**, 고온·고밀도에서 급팽창. 1초 때 100억 도, 3분 후 10억 도, 100만 년 후 3,000도. 이때 생긴 **수소 75% + 헬륨 25%**가 현 우주 질량 대부분 |
| 1948 앨퍼·허먼 | 초기 우주의 흔적인 복사선(**우주배경복사**)이 남아 있고 그 온도를 약 영하 268도로 예측 |
| 1948 호일·본디·골드 | **정상우주론(steady state)**: 우주는 옛날이나 지금이나 늘 같은 꼴, 특이점을 피함. 빅뱅과 선의의 경쟁 |
| 1964 펜지아스·윌슨 | 벨 연구소에서 **우주배경복사 발견** (3.5K, 예측치와 1.5도 차이) → **빅뱅의 강력한 증거**. 1978 노벨물리학상 |
| 1980 구스(Guth) | **인플레이션(급팽창) 가설** @MIT: 빅뱅 1초 이내에 우주가 엄청나게 커짐 → **등방성 문제** 해결 |

- **빅뱅(대폭발) 우주론의 증거 3가지**: ① 허블의 은하 **적색이동** ② 가벼운 원소(수소·헬륨)의 풍부한 존재 ③ **우주배경복사**

### 4) 빅뱅이란?

- 처음 **시간과 공간이 태어나는 시점**. 태초엔 은하·별·원자·시간·공간이 없었다
- **특이점**: 밀도·온도·에너지가 무한대인 수학적 점. 진공의 양자역학적 요동이 만들어냄
- 약 **138억 년 전** 특이점에서 갑작스러운 대폭발 → 시간·공간 생성과 함께 우주 전체가 팽창 시작
- (참고) 1980년대엔 우주 나이를 150억 년으로 봤으나, 현재는 **138억 년**

### 5) 우주 초기 연대기 (시간 순서 매우 중요)

- 필요한 이론: **양자역학**(미시 세계) + **일반상대성이론**(중력) → 둘을 결합한 **양자중력이론** 필요(끈이론·대통일장이론 등). 중력은 여전히 가장 이해하기 어려운 힘

| 시점 | 사건 |
|------|------|
| 10⁻³⁷초 후 | **급팽창(Cosmic Inflation)** 시작 — 순식간에 관측 가능한 우주 전체보다 더 커짐. 현재 관측 가능 우주는 전체의 아주 작은 일부 |
| (급팽창 직후) | 최소 6개의 **쿼크(Quark)** 생성 |
| — | 4가지 기본 힘 전달 입자 생성: 중력(중력자), 전자기력(광자), 약력(W·Z 입자), 강력(글루온) |
| 10⁻⁶초 후 | 쿼크 결합 → **양성자**(up 2 + down 1), **중성자**(up 1 + down 2). 핵력이 쿼크를 붙잡음. 반양성자·반중성자도 형성 |
| 1초 후 | 중성미자·전자 형성, 반물질(양전자·반중성미자)도 형성. 물질+반물질 → 감마선 방출하며 소멸. **물질이 반물질보다 약간 많아** 남은 물질이 현 우주를 구성 |
| 몇 분 후 | 온도 수십억 도로 감소 → 양성자+양성자 핵융합으로 **헬륨 원자핵**, 양성자+중성자로 **중수소 원자핵**. 대부분 양성자는 수소 원자핵 |
| 3~4만 년 후 | 감마선이 넓은 공간으로 퍼져 감마선 시대 종료. 전자+양성자 결합 → **수소 원자** 형성, 자외선 방출 → 팽창으로 가시광선·적외선 거쳐 현재 **마이크로파 우주배경복사**로 관측 |

- 우주 초기의 우연한 **밀도 요동** → 점차 대규모 비균질 물질 분포로 성장 → 밀도 높은 곳에서 중력으로 수소가스 구름 형성 → 압축되어 별 → 수천억 개 모여 은하 → 국부은하군·은하단 → 초은하단 → 거대벽(Great Walls), 반대로 빈공간(Voids)

### 6) 우주의 구성

| 구분 | 비율 | 내용 |
|------|------|------|
| **물질** | 약 4% | 별·성간가스·은하·은하단·거대벽 등의 총질량 |
| **암흑물질** | 약 23% | 중력으로 끌어당기나 보이지 않아 실체 불명 |
| **암흑에너지** | 약 73% | 중력에 반대되는 힘으로 물질을 밀어내 **가속 팽창**시키는 에너지, 실체 불명 |

- 현재 우주의 대부분은 **암흑에너지**로 존재

### 7) 우주의 운명

- 우주가 영원히 팽창할지, 팽창·수축을 반복할지 구별하는 방법:
  1. **우주 물질의 재고(총량)** 조사
  2. **코스모스의 끝(영원의 벼랑 끝)**까지 가 보기
- 팽창 원인: 팽창력이 우주 물질(중력)보다 크면 팽창. 수축 원인: 중력
- **우주진화론**: 수축(닫힌 우주)·팽창(열린 우주)·정지(정상 우주). 아인슈타인의 장 방정식을 우주에 적용(프리드만·르메트르·로버트슨–워커). 현재 관측상 우주는 **팽창**
- 물질 재고 문제: 관측 가능한 물질만으로는 부족 → **암흑물질** 도입, 그래도 부족 → 가속 팽창을 설명할 **암흑에너지** 필요
- **아인슈타인의 우주상수** = 우주의 척력으로 작용 (현재 암흑에너지와 연결). 단, 암흑물질·암흑에너지의 구체적 설명은 아직 불명확

# 1주 2강 — 영화의 시작과 배경

> 영화예술과 문화생활 · 공연예술학과 박근수 교수
> 학습목표: 영화가 어떤 배경에서 탄생했으며, 당시의 영화적 환경은 무엇이었는가

---

## 1. 수업 요약

영화의 **기원 → 탄생의 전조 → 탄생(에디슨·뤼미에르) → 탄생 배경(산업화·도시화) → 종합예술로서의 영화**로 이어지는 흐름을 다룬다. 영화는 인간의 "이미지를 기록·재현하려는 욕망"에서 출발해, 여러 잔상효과 놀이기구를 거쳐, 에디슨이 결정적 계기를 만들고 **뤼미에르 형제의 시네마토그래프**로 본격 탄생했다. 이후 산업화·도시화라는 사회적 배경 속에서 대중오락으로 자리 잡고, 쇼트 연결을 통한 내러티브를 갖추며 **제7의 예술(종합예술)**로 발전한다.

---

## 2. 개념 정리

### (1) 영화의 기원 — 이미지에 대한 인간의 욕망
- 영화의 기원 = **이미지 기록에 대한 욕망 + 현실을 복제·재현하려는 인간의 욕망과 노력**
- 그림(스틸)과 달리 영화는 **이미지를 연속적으로 나열** → 움직임의 신기함 = **잔상효과**
- 어원으로 본 본질(움직임·동적):
  - 영어권: **Movie / Motion Pictures** ← movement, move
  - 프랑스: **Cinema**, 독일: **Kino** ← kinetic / kinematic
- 본질 정의: **"시간 속에서 흘러가는 현실의 장면을 붙잡고 재현하고 싶은 인간의 욕망이 반영된 매체"**

### (2) 영화 탄생의 전조 (잔상효과·착시 이용 놀이기구)
| 순서 | 장치 | 시기/인물 | 특징 |
|---|---|---|---|
| 1 | 플립북 | 16세기 유럽 | 종이 묶어 그림, 넘기면 움직이는 듯한 착시 |
| 2 | 카메라 옵스큐라 | 16세기 이탈리아·레오나르도 다빈치 | 빛에 의한 그림자 투영, **현대 카메라 암실 원리** |
| 3 | 소마트로프 | 1826년 ("요술회전") | 양면 그림 회전 → 제3의 합성 이미지 |
| 4 | 조트로프 | 영국 | 구멍 뚫린 회전 원기둥, 띠 그림 회전 |
| 5 | 프락시노스코프 | 프랑스 에밀 레이노 | 빛과 거울로 내부 이미지를 외부 투영 → **오늘날 영사기 형태** |
| 6 | 마이브리지 실험 | 1876~1878 영국 | **24대 카메라**로 질주하는 말 촬영, **1초 24프레임 = 현대 영상원리의 시초** |

### (3) 영화의 탄생
- **토마스 에디슨 — 영화 탄생의 "결정적 계기"**
  - 1877 원통 축음기 발명 → 부수적 시각장치
  - 1889~1893 **키네토폰(촬영기)**, **키네토스코프(영사기)** 발명 → 박스 형태, **한 번에 한 사람만 관람**
  - **블랙마리아**: 최초의 스튜디오(지붕 열어 태양광 이용)
  - 1908 영화특허회사 설립 → 특허료 부담 피해 독립제작사들이 **서부(LA·헐리우드)로 이동 → 헐리우드 탄생 배경**
  - **한계: 한 사람만 볼 수 있어 본격적 탄생으로 보지 않음**
- **뤼미에르 형제(루이·오귀스트) — 영화의 "본격적 시작"**
  - **시네마토그래프**: 재봉틀 원리로 필름에 구멍, 1초 16장 촬영
  - **전력 불필요 → 이동 가능 + 여러 사람 동시 관람** (촬영·상영 모두 가능)
  - 최초의 영화: 〈기차의 도착〉, 〈공장을 떠나는 노동자들〉 (1분 내외)
  - **vs 스코프(망원경 어원)**: 시네마토그래프는 여러 사람이 동시에 감상 → 혁신 → **영화의 탄생**

### (4) 영화 탄생의 배경 (사회·문화)
- 19세기 **산업혁명 → 공장 → 도시 형성 → 임금노동자 → 오락거리 수요 → 영화관 탄생**
- 도시 자체가 **영화의 소재** 제공
- 상영 공간: 카페·콘서트홀 (뤼미에르 첫 상영지 = **그랑카페**), 보드빌/버라이어티 쇼의 일부로 상영, 극장주의 지방 순회 이동영업
- **사실의 재현 → 이야기 속으로**: 뤼미에르 〈정원사〉(작은 이야기), 그리피스 〈국가의 탄생〉(1914, 딕슨 소설 각색, 최초의 장편)

### (5) 종합예술로서의 영화
- 시각이미지·스토리텔링·음악·건축·첨단기술이 종합 → **종합예술**
- 쇼트 연결 → 내러티브 + 자유로운 시공간 창조
- **제7예술론**: 1911년 이탈리아 **리치오토 카누도** — 음악·무용·회화·건축·연극·문학에 이은 **7번째 예술**
- **발터 벤야민**: 〈기술복제시대의 예술작품〉 — 영화는 대량복제·대량소비 기반 → 대중문화 선도
- 영화 = **대중예술** (고급예술과 대비), **상업성 + 오락성**이 본질

## 3. 강조한 부분 (★ 시험 포인트)

- ★★★ **"영화는 상업성과 오락성을 빼고는 얘기할 수 없다"** — 교수가 "굉장히 중요"하다고 직접 강조
- ★★★ **쇼트(Shot) 개념**: "중단 없이 한 번에 촬영된 필름톤(하나의) 장면" — "잘 알고 계셔야 한다"고 명시. 쇼트 연결 → 이야기·환상(일루전) 탄생
- ★★ **에디슨(결정적 계기) vs 뤼미에르 형제(본격적 시작)** 구분 — 차이는 **한 사람 관람 vs 여러 사람 동시 관람** (반복 강조)
- ★★ **1초 24프레임**(마이브리지/현대 영상원리) vs **시네마토그래프 1초 16장**의 차이
- ★ **제7예술론** = 카누도, 6개 기존 예술(음악·무용·회화·건축·연극·문학)에 이은 7번째

## 4. 특이점 / 기타

- 교수 개인 일화: 어릴 적 교과서 끝에 그림 그려 넘기던 플립북 놀이, 어린이대공원 "상상나라"의 소마트로프·조트로프 체험 기구
- 헐리우드의 탄생 배경이 **에디슨 특허료 회피**라는 점이 흥미 포인트
- 현재 카메라/폰은 1초 30~60프레임까지 촬영 (과거 24프레임과 비교)
- 다음 강의 예고: 뤼미에르 형제 영화들 + 조르주 멜리에스 〈달나라 여행〉 직접 감상

# 6주 2강 — 영화 형식과 카메라 (2): 숏 크기·앵글·카메라 움직임

> 영화예술과 문화생활 · 공연예술학과 박근수 교수
> 학습목표: 촬영의 개념, 카메라의 위치·앵글·움직임, 그에 따른 영상 종류와 미학

---

## 1. 수업 요약

촬영을 구성하는 세 축 — **카메라 위치(숏의 크기), 카메라 앵글, 카메라 움직임**을 다룬다. 영화의 기본 단위인 숏부터 시작해, 피사체와의 거리에 따른 숏 크기, 촬영 각도에 따른 앵글의 의미, 그리고 다양한 카메라 움직임 기법과 그 미학적 효과를 정리한다.

---

## 2. 개념 정리

### (0) 기본 단위
- **숏(Shot)**: 영화의 가장 기본 단위. 컷 중간에 끊기지 않고 이어지는 장면. 여러 프레임으로 구성 (1초~몇 분)
- **위계: 숏 → 씬(Scene) → 시퀀스(Sequence) → 영화**
- **테이크(Take)**: 카메라 버튼을 누르고 "레디 액션"~"컷"까지 한 번 돌아간 것 (숏과는 다른 의미)

### (1) 카메라 위치 = 숏의 크기 (카메라–피사체 거리)
| 숏 | 범위 | 용도/특징 |
|---|---|---|
| 익스트림 롱샷 | 극단적으로 먼 거리 | 지평선·수평선, 피사체 거의 안 보임 |
| **롱샷(Long Shot)** | 먼 거리, 피사체+환경 전체 | 시공간 정보, **시퀀스 시작 = 설정화면/마스터샷** |
| 풀샷(Full Shot) | 인물·배경 전체(머리~발끝) | 도입부 |
| **미디엄샷(Medium Shot)** | 머리~허리 | 대화 장면, 원샷/투샷/쓰리샷, **오버 더 숄더 샷** |
| 니샷(Knee Shot) = 아메리칸 샷 | 머리~무릎(삼반신) | **서부활극**(총잡이 총 뽑는 순간) |
| **클로즈업(Close-up)** | 얼굴·손 등 확대(머리끝~가슴) | 중요성 강조·상징, 표정·눈물 |
| 익스트림 클로즈업 | 눈동자·입술만 극단 확대 | 강조 극대화 |

### (2) 디포커스(딥포커스, Deep Focus) ★ 꼭 알아두기
- **전경·중경·후경의 모든 피사체가 선명하게 보이도록 깊은 심도로 찍는 것** (광각렌즈 + 작은 조리개)
- 한 장면에 여러 시각·서사 정보를 주고, 모든 대상을 균등히 보여줘 관객의 가치 판단을 유도
- 오슨 웰스 〈시민 케인〉 → **사실주의적 화면 구성** (↔ 클로즈업의 아웃포커스 배경)

### (3) 카메라 앵글 (촬영 각도)
- **아이레벨 / 미디엄 앵글**(눈높이): 가장 기본·안정 (뉴스 아나운서)
- **로우 앵글(앙각)**: 아래에서 위로 → **권위·압도감·웅장함, 속도·운동감** (〈시민 케인〉 케인의 카리스마)
- **하이 앵글(부감)**: 위에서 아래로 → 피사체 작게, **운명·숙명·무기력·불안, 신의 시점**
- **다다미 앵글**: 오즈 야스지로가 개발(〈동경이야기〉). 삼각대를 잘라 앉은 키(다다미 마루)에 맞춰 아이레벨로 촬영
- **사각 앵글(캔티드 앵글)**: 카메라를 좌우로 기울임 → 환각·비현실·악몽·취한 상태 (올리버 스톤 〈내추럴 본 킬러〉)
- **버즈아이뷰**: 새가 하늘에서 내려다보는 각도 (드론·헬리콥터)

### (4) 카메라 움직임 (※ 극적 동기가 있어야 함)
- **팬(Pan)**: 삼각대 고정 + 좌우 회전 (가장 흔함, 피사체 따라가기)
- **틸트(Tilt)**: 삼각대 고정 + 상하 수직 (심리효과, 동시성·인과관계)
- **달리(Dolly)**: 바퀴 달린 탈것에 카메라를 싣고 이동 (수색·추적)
- **트래킹(Tracking)**: 트랙(레일)을 깔고 그 위에서 이동 → 매우 스무스(준비에 시간 多)
- **크레인(Crane)**: 대형 기계팔로 허공에서 자유롭게 이동 → 큰 스케일
- **핸드헬드**: 카메라를 들고 직접 이동 → 흔들림·거친 효과 (다큐멘터리)
- **스테디캠(Steadicam)**: 몸에 충격완화 장치 착용 → 핸드헬드처럼 찍되 스무스 (대여료 비쌈 → 예산 영향)
- **줌(Zoom)**: 렌즈로 당기고 밀기 → 인위적 움직임, 화면 크기 조절
- **영화사 최초의 카메라 움직임**: 무르나우 〈마지막 웃음〉 — 촬영감독 칼 프로인트가 카메라를 자전거에 고정해 구현

---

## 3. 강조한 부분 (★ 시험 포인트)

- ★★★ **딥포커스(디포커스)** = 화면 안 모든 피사체에 포커스 — "꼭 알아두라"고 명시
- ★★★ **숏 위계: 숏 → 씬 → 시퀀스 → 영화**
- ★★ **숏 크기 종류**(롱샷·풀샷·미디엄·클로즈업) + 롱샷 = 설정화면
- ★★ **앵글별 의미**: 로우 앵글=권위·압도 / 하이 앵글=무력·운명·불안
- ★ 다다미 앵글(오즈 야스지로), 사각 앵글(캔티드), 카메라 움직임 종류
- ★ 숏 vs 테이크 구별

---

## 4. 특이점 / 기타

- 니샷 = 아메리칸 샷: 서부활극에서 총잡이가 총 뽑는 순간을 잡으려 미국에서 많이 쓴 데서 유래
- 다다미 샷: 실제로 삼각대를 잘라 낮춰 촬영
- 무르나우 〈마지막 웃음〉 = 영화사 최초의 카메라 움직임(자전거 활용)
- 스테디캠 vs 핸드헬드 선택이 예산에 영향
- 다음 강의 예고: **편집과 몽타주** (영화에서 매우 중요)

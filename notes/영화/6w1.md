# 6주 1강 — 영화 형식과 카메라 (1): 구도·프레임·미장센·조명·컬러

> 영화예술과 문화생활 · 공연예술학과 박근수 교수
> 학습목표: 영상의 스타일, 구도, 프레임, 미장센, 조명, 컬러 이해

---

## 1. 수업 요약

영화를 결정짓는 핵심은 **영상 그 자체**임을 전제로, 영상을 구성하는 5대 형식 요소 — **구도·프레임·미장센·조명·컬러**를 차례로 다룬다. 영상은 감독과 촬영감독(조명 포함)에 의해 결정되며, 각 요소는 감독이 메시지를 관객에게 전달하는 **비언어적 커뮤니케이션** 수단이다.

---

## 2. 개념 정리

### (1) 영화의 형식
- 영화를 결정짓는 가장 중요한 요소 = **영상 그 자체** (감독 + 촬영감독이 결정, 촬영감독은 조명 포함)
- **TV vs 영화**: 프레임/스크린 사이즈가 다름 → 촬영·조명·사운드·연기에 차이
- 영화는 대형 스크린 → 디테일이 중요 → 구도·프레임·미장센·컬러의 세심한 연출 필요 (예: 봉준호 = "봉테일")

### (2) 구도 (Composition)
- **정의: 화면 속 인물·사물을 공간에 어떻게 배열·배치하는가 = 영화 속 공간 구성 방식**
- 핵심: **3차원 현실 → 2차원 스크린 → 2차원 평면에 다시 3차원 깊이감을 창조**
- 심리적 효과 이용: 왼쪽→오른쪽 방향 = 안정감 / 비틀어진 사선 = 내면적 불안 (독일 표현주의, 필름 누아르 〈이중배상〉 빌리 와일더)
- 예: 트뤼포 〈쥘과 짐〉(삼각구도로 세 인물 관계 형성), 파스빈더 〈불안은 영혼을 잠식한다〉(대칭적·극단적·2차원적 구도 → 서로 타인임을 암시)
- 목적: 구도를 위한 구도가 아니라 **관객의 주의를 집중시키고 주제를 전달하는 의사소통 수단**

### (3) 프레임 (Frame)
- **정의: 영상 한 장이 스크린에 영사될 때 보이는 영역 = 영상 한 장의 사이즈**
- 관객이 환상의 세계로 들어가는 **출입구**(창문·창틀 비유), 봐야 할 것/보지 말아야 할 것을 구분
- 상징: 윗부분 = 권력·열망 / 아랫부분 = 취약·무력·굴종 / **오프스크린 = 어둠·신비·죽음** (프리츠 랑 〈M〉(1931): 유아살해범 존재를 오프스크린으로 암시)
- **화면 비율(종류)**:
  - **1.33:1** (4:3, 옛날 TV·키네토스코프)
  - **1.85:1 = 비스타비전**
  - **2.35:1 = 시네마스코프** (긴 와이드 화면)
  - **16:9** (요즘 가장 많음, DVD·HDTV)
- 필름: **35mm vs 70mm** (70mm가 더 많은 화면을 담음)
- 와이드스크린으로 찍은 영화를 표준 스크린으로 배급하면 영상의 30%가 잘림 (큐브릭 〈2001 스페이스 오디세이〉) → 감독·촬영감독은 사이즈를 미리 계산해야 함

### (4) 미장센 (Mise-en-scène) ★ 어쩌면 영화에서 가장 중요
- **정의: 영상 안 배경·인물·사물·소품(대소도구)을 극적 분위기와 의미를 위해 배치하는 것 = 장면화 = 총체적 시각요소의 배치**
- 어원: **프랑스 연극 용어**
- 전경·중경·후경 배치 → 2차원 화면에 3차원 깊이감 부여
- 현대에는 **프로덕션 디자이너**가 대도구·세트 등 미술을 관할 (감독·촬영감독과 합의)
- 예: 오슨 웰스 〈시민 케인〉(컵·숟가락·약병 배치로 약 복용 암시), 박찬욱 〈올드보이〉(벽지·등·거울), 이창동 〈시〉, 임권택 판소리 영화

### (5) 조명 (Lighting) — "영화는 조명의 예술"
- 빛의 명암 대비가 영화의 스타일을 만듦. 조명감독은 배우 동선을 예상해 미리 설치(리허설 활용), 빛의 강도·방향·속성을 이해해야 함
- **빛의 강도**: **하이키(High-key, 밝음/명조 → 코미디)** ↔ **로우키(Low-key, 어둠/암조 → 스릴러·공포·필름 누아르)**
  - 장이머우 〈붉은 수수밭〉 = 하이키 / 데이비드 핀처 〈세븐〉 = 로우키
- **빛의 방향**: 순광(평면적) / 측광 / 역광(뒤에서)
- 표현주의 = 인공광 / 사실주의(네오리얼리즘·누벨바그) = 자연광 / 헐리우드 고전주의 세트 = 인공광
- 촬영감독 vs 조명감독: 한국은 분리되는 경우가 많음, **미국은 촬영감독이 조명까지 관장(DP 시스템)**

### (6) 컬러
- 컬러 필름 = **1940년 이후**. 〈국가의 탄생〉의 불타는 장면은 필름에 직접 색칠
- 컬러는 심리적·잠재적 요소로 정서를 강화
- 예: 스필버그 〈쉰들러 리스트〉(흑백 속 빨간 옷 소녀 강조), 팀 버튼 〈가위손〉(환상적·동화적 컬러), 키에슬로프스키 〈세 가지 색: 블루〉(허무·고독·죽음·고통 상징)

---

## 3. 강조한 부분 (★ 시험 포인트)

- ★★★ **미장센 = 영화에서 가장 중요** (총체적 시각요소의 배치, 프랑스 연극 용어)
- ★★★ **구도 vs 프레임 구별**: 구도 = 공간 구성 방식 / 프레임 = 보이는 화면의 사이즈
- ★★ **하이키 vs 로우키** (밝음/명조-코미디 ↔ 어둠/암조-스릴러·공포)
- ★★ **화면 비율**: 1.33:1 / 1.85:1(비스타비전) / 2.35:1(시네마스코프) / 16:9
- ★ "영화는 조명의 예술" / 오프스크린 = 어둠·신비·죽음

---

## 4. 특이점 / 기타

- 봉준호 별명 "봉테일"(디테일에 집착)
- DP 시스템: 한국은 촬영·조명 분리 관습 ↔ 미국·해외파 젊은 촬영감독은 조명까지 통합 관장
- 와이드스크린 영화의 표준 스크린 배급 시 30% 손실 문제
- 다음 강의 예고: 카메라 위치, 앵글, 움직임

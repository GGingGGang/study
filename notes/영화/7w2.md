# 7주 2강 — 영화 편집 (2): 러시아 형식주의·몽타주·장면 전환 기법

> 영화예술과 문화생활 · 공연예술학과 박근수 교수
> 학습목표: 러시아 형식주의와 쿨레쇼프 실험, 에이젠슈타인의 몽타주, 여러 장면 전환 기법

---

## 1. 수업 요약

편집의 두 번째 시간. **러시아 형식주의**를 토대로 **쿨레쇼프의 실험 → 푸도프킨 → 에이젠슈타인**으로 이어지는 몽타주 이론의 확립을 다룬다. 특히 에이젠슈타인의 **충돌 몽타주와 5가지 몽타주 유형**(〈전함 포템킨〉 오데사 계단)이 핵심이며, 마지막으로 실무에서 쓰이는 다양한 **장면 전환 기법**을 정리한다.

---

## 2. 개념 정리

### (1) 러시아 형식주의
- 1917 **볼셰비키 혁명** 후, 예술가들이 사회주의 혁명을 교육하고 정부가 적극 지원
- 배경 사상: 헤겔 변증법, 마르크스 유물론, 레닌 사회개혁론
- 미장센 구성보다 **샷과 샷의 연결성(편집)을 통한 새로운 의미 창조**에 관심 → 문학의 "내용보다 형식" 강조가 영화 편집 실험으로 이어짐

### (2) 쿨레쇼프(Kuleshov) — 러시아 몽타주 이론 창시자
- **쿨레쇼프 효과: 배우의 연기가 아닌 몽타주(샷의 연결)만으로 인물의 감정·심리, 나아가 존재하지 않는 의미까지 창조**
  - 무표정한 얼굴 + 관(시신) → 슬픔 / 무표정한 얼굴 + 음식 → 배고픔
- 영화적 의미 = 두 개 이상의 쇼트 병치·연결로 창조 (쇼트는 철저히 구성·조립되어야)
- **에이젠슈타인의 스승**

### (3) 푸도프킨(Pudovkin)
- 편집이 영화의 기초, 조립·구성으로 의미 창조
- 단, **그리피스의 연속편집 영향에서 벗어나지 못함**(감정적 효과 극대화 = 고전주의의 한계)
- 고리키 소설 〈어머니〉(1926) 영화화
- → **쿨레쇼프 → 푸도프킨 → 에이젠슈타인**에서 러시아 몽타주 확립

### (4) 세르게이 에이젠슈타인 ★ 핵심
- 라트비아 출생(독일계 건축기사의 아들, 건축·연극·심리학 공부), 러시아 혁명 때 적군 자원입대·프로파간다 선전반 활동
- 1925 〈파업〉 데뷔, 〈전함 포템킨〉, 〈10월〉 → 소련 무성영화 황금기
- **몽타주 = '조립한다'는 뜻** (필요 없는 부분을 잘라내는 '커팅'과 다름)
- **미국 = 자연스러운 서사 전달(몰입·감정이입)** ↔ **러시아 = 비연속적 편집·파편화된 현실 모방·이데올로기 선전**
- **핵심 이론(충돌 몽타주)**: 쇼트와 쇼트는 단순 결합·나열이 아니라 **충돌과 갈등의 관계**로 이어져야 더 많은 의미 → 헤겔 **변증법(정반합)**: 두 장면이 충돌하면 새로운 의미의 장면
  - 〈파업〉: 시위군중 학살 + 소 도살 장면을 충돌 → 이데올로기적 의미
- **에이젠슈타인의 5가지 몽타주** (〈전함 포템킨〉 오데사 계단 시퀀스):
  1. **운율(Metric) 몽타주**: 긴 쇼트와 짧은 쇼트의 충돌 (계단 굴러내려가는 유모차 + 학살 장면 짧게 교차)
  2. **율동(Rhythmic) 몽타주**: 정지된 것과 움직이는 것의 충돌 (직선 전진하는 군대 vs 우왕좌왕 도망가는 민중)
  3. **음조(Tonal) 몽타주**: 어둠과 밝음 / 평면과 입체의 충돌 (빛과 그림자, 죽은 아이를 안은 어머니)
  4. **배음(Overtonal) 몽타주**: 위 세 가지가 복합 적용
  5. **지적(Intellectual) 몽타주**: 은유·상징으로 충돌 (사자상 등 상징으로 의미 전달)

### (5) 장면 전환 기법
- **플래시백(Flashback)**: 과거 회상으로 전환 (임권택 〈서편제〉: 창 부르는 얼굴 클로즈업 → 과거 / 유사성 활용: 커피잔→자동차 바퀴, 〈블루벨벳〉 귀 자름→가위 테이프)
- **페이드 인/아웃**: 어둠에서 밝아짐 / 점점 어두워짐 (영화 시작에 페이드 인)
- **디졸브(Dissolve)**: 선행 장면이 후행 장면에 서서히 겹침 → 시간 경과·감성적 분위기 (〈쇼생크 탈출〉)
- **오버랩(Overlap)**: 두 장면을 두껍게 중첩
- **와이프(Wipe)**: 선행 장면을 밀어내는 전환 (자동차 와이퍼처럼, 〈스타워즈〉)
- **롱테이크(Long Take)**: 편집(커트) 없이 하나의 테이크로 길게 → 서사 연속성·공간 깊이 (봉준호 〈살인의 추억〉, 〈버드맨〉)

## 3. 강조한 부분 (★ 시험 포인트)

- ★★★ **쿨레쇼프 효과**: 연기가 아닌 몽타주(샷 연결)만으로 감정·심리·의미 창조
- ★★★ **에이젠슈타인 충돌 몽타주** = 쇼트의 충돌·갈등(정반합) → 새로운 의미
- ★★★ **에이젠슈타인 5가지 몽타주**: 운율 / 율동 / 음조 / 배음 / 지적
- ★★ **〈전함 포템킨〉 오데사 계단** = 가장 위대한 몽타주 시퀀스
- ★★ **장면 전환 기법**: 플래시백 · 페이드 인/아웃 · 디졸브 · 오버랩 · 와이프 · 롱테이크
- ★ 몽타주 = '조립'(↔ 커팅 = '잘라내기') / 미국 연속편집(몰입) ↔ 러시아 몽타주(선전)

---

## 4. 특이점 / 기타

- 계보: 쿨레쇼프(창시) → 푸도프킨(고전주의 한계) → 에이젠슈타인(확립·혁신)
- 미국 vs 러시아 편집관의 근본적 대비(서사 몰입 ↔ 이데올로기 선전)
- 롱테이크 명장면: 〈살인의 추억〉, 〈버드맨〉
- 다음 강의 예고: **영화 사운드**
